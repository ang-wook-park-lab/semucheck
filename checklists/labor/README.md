## 조건부 문항 (`applies_if`)
- `employees >= 10`: 취업규칙 작성·신고, 괴롭힘 예방 규정

- 게이트 질문: 취업규칙 개정 여부(LAB-010), 근로시간 제도(LAB-022), 포괄임금제(LAB-030), 연차 촉진 방식(LAB-038), 최근 괴롭힘 신고(LAB-052), 해고 검토 대상(LAB-065)
- 게이트에 아직 답하지 않았으면 후속 문항을 일단 보여 주고, 답하면 해당 없는 문항이 사라집니다.
