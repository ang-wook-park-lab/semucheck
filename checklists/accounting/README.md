- 파일: `accounting-diagnosis.json` (74문항, 위험 규칙 방식 — 형식은 `schema/checklist-item.schema.json`)
- 근거: **제공된 회계 지침이 없어서** ① 저장소의 기존 정리(정책자금 도서 1부 7장 가결산·결산, 14부 재무제표 5대 위험 항목, 15부 재무등급·분식 징후, 1부 T1~T3 세무, 법인 일반관리 점검표 02·03영역)와 ② 회계·세무 실무 일반 지식으로 작성한 초안입니다. 문항의 `source`에 어느 근거인지 적었습니다. 설명 자료는 `knowledge/accounting/`
- 상태: **초안** — 세무사/회계사가 조문·기한·가산세율을 원문으로 대조한 뒤 `verified_at`에 확인일을 적습니다.
  - 불확실한 사안에는 `[실무자 확인 필요: 세무사/회계사 크로스체크 요망]`을 붙였고, 한도·세율 같은 숫자는 문항에 넣지 않고 "해당 연도 기준 확인"으로 안내했습니다.
  - 작성 시점에 2026년 개정·고시 반영 여부를 확인하지 못했습니다.

## 조건부 문항 (`applies_if`)
- `business_type == '법인'`: 법인세·전자세금계산서·재무제표 승인·배당·임원 보수 등
- `business_type == '개인'`: 복식부기·사업용계좌·종합소득세
- `has_research_lab == true`: 연구개발비 세액공제 증빙
- 게이트 질문: 가지급금(ACC-030), 영세율 거래(ACC-015), 업무용 승용차(ACC-047), 특수관계 거래(ACC-062)
- 게이트에 아직 답하지 않았으면 후속 문항을 일단 보여 주고, 답하면 해당 없는 문항이 사라집니다.

## 정보 수집용 문항 (위험 판정 없음, `risk_rule: False`)
ACC-015, 047, 062 — 후속 문항을 정하는 문항입니다.

## 정책자금 진단(FUND)과의 관계
가지급금·가수금·자본잠식·영업이익 적자·개발비 같은 재무 리스크는 정책자금 진단(FUND-021 등)에도 있습니다. 회계 진단에서는 **정리 방법과 세무 처리(인정이자, 손금불산입)** 중심으로 묻고, 정책자금 진단에서는 **신청 가능성** 중심으로 묻습니다.
