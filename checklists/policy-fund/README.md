## 수임 판정 로직 (책 63장)
- **즉시 수임**: 빨강 0개 + 대표 신용 5등급 이내 + 매출 증가 + 자금 목적 명확 + 인증 1개 이상
- **준비 후 수임**: 빨강 0개, 노랑 일부(가지급금·신용 5~6등급·인증 없음) → 3개월 준비 로드맵
- **수임 불가**: 세금 체납, 신용불량, 자본잠식, 진행 중 소송, 대표 파산·회생

## 추천 자금 매칭 (결과 화면용, 책 2·55·62·67장)
| 조건 | 1순위 검토 |
|---|---|
| 상시 5인 미만(소상공인) | 소진공 자금(일반경영안정, 성장기반 등) + 지역 신용보증재단 |
| 업력 7년 미만 | 중진공 창업기반지원(청년 39세 이하·3년 미만은 청년전용) + 기보 기술보증 + 창업성장 R&D |
| 업력 7년 이상, 설비투자 | 중진공 신성장기반·혁신성장지원 시설자금 + 기보·신보 운전자금 |
| 신용 BB 이상 + 벤처·이노비즈 | 한은 C2 온렌딩 / BB+ 이상이면 산은 온렌딩 |
| 특허 보유 | 기보 IP보증(특신전 조합 최대 3억), 신보 IP 우대보증, 중진공 개발기술사업화 |
| 매출 10% 이상 감소·재해 | 중진공 긴급경영안정(수시 접수) / 소진공 긴급경영안정(15% 감소) |
| 대기업·공공기관 납품, 결제 60일 이상 | 중진공 밸류체인안정화(팩토링), B2B 구매자금 |
| 7% 이상 고금리 대출 보유 소상공인 | 소진공 대환대출(4.5% 고정, 10년) |
