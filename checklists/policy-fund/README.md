# 정책자금 진단 체크리스트

- 파일: `fund-diagnosis.json` (76문항: FUND-001~048 + 16부·부록 반영 FUND-049~076)
- 출처: `knowledge/policy-fund/kms-integrated/` (강민수, 정책자금·인증·R&D 통합 실무서, 2026)
- 상태: **초안** — 컨설턴트 검토 후 `verified_at`에 확인일 기입
- 조건부 문항은 `applies_if`에 적용 조건을 적었습니다(예: 법인사업자만, 연구소 보유 기업만). 조건에 쓴 변수 이름(`business_type`, `has_research_lab` 등)은 웹 화면을 만들 때 고객사 정보 입력 항목과 맞춰야 합니다.

## 16부·부록 반영 내용 (FUND-049~076)
- **신용평가 감점 요인 임계값**(별첨 표): 단기차입금 40%·총차입금 70%·매출채권 40%·매출원가율 85%·현금비율 3%·자산 5% 감소·토지건물 20% 감소 등 + 5개 불량 항목 중 가수금·개발비 과대계상 → 신용·재무
- **중진공 업종별 융자제한 부채비율 초과**(빨강, FUND-064): 비율 숫자는 문항에 고정하지 않고 신청 연도 공고로 확인
- **정관·등기·지배구조**: 임원퇴직금·보수규정, 정관-등기 일치, 의사록, 변경등기, 차명주식, 직무발명보상 4단계 절차 → 운영 리스크
- **가점·인증**: 지식재산경영인증, 조달 신인도 가점, 벤처 연구개발유형 요건 → 가점요소
- **준비도·사후관리**: 여신 준비서류 6종, 공장 취득 세금 감면 확인, 연구소 사후관리(인원·공간·연구노트)

## 법령·수치 확인이 필요한 문항
책 안에서 수치가 서로 다르거나 법령 개정 가능성이 있어 `verified_at`을 비워 둔 채 `help`·`legal_basis`에 확인 필요를 적은 문항입니다.
- 융자제한 부채비율(FUND-018, FUND-064): 제조업 340.2%(1부)와 391.0%(76장) 불일치
- 임원퇴직금 규정(FUND-065): 법인세법 시행령상 한도 배수 현행 기준
- 연구소 사후관리(FUND-076): 중견기업 연구전담요원 5명(76장 본문)과 7명(부록 B) 불일치
- 근거 조문을 적은 문항(상법·상증세법·지방세특례제한법·발명진흥법)은 책이 적었거나 제가 아는 조문이므로 원문 대조 후 확정

## 수임 판정 로직 (책 63장)
- **즉시 수임**: 빨강 0개 + 대표 신용 5등급 이내 + 매출 증가 + 자금 목적 명확 + 인증 1개 이상
- **준비 후 수임**: 빨강 0개, 노랑 일부(가지급금·신용 5~6등급·인증 없음) → 3개월 준비 로드맵
- **수임 불가**: 세금 체납, 신용불량, 자본잠식, 진행 중 소송, 대표 파산·회생

## 추천 자금 매칭 (결과 화면용, 책 2·55·62·67장)
| 조건 | 1순위 검토 |
|---|---|
| 상시 5인 미만(소상공인) | 소진공 자금(일반경영안정, 성장기반 등) + 지역 신용보증재단 |
| 업력 7년 미만 | 중진공 창업기반지원(청년 39세 이하·3년 미만은 청년전용) + 기보 기술보증 + 창업성장 R&D |
