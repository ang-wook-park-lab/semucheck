# 근태·연차 관리 (연장근로 위반 방지)

> 표준 모델 예시: 선택적 근로시간제(1개월 정산) / 전체 150명 / 리스크 = 주 52시간 초과 임박자 발생, 연차 미소진에 따른 수당 부담과 휴식 부재
> 체크리스트: LAB-022~046 · 출처 표기는 모두 `2026년 기준 확인 필요`

## STEP 1. 법적 한계선과 연차 촉진 시한
| 영역 | 기준 | 출처 |
|---|---|---|
| 기본 근로시간 | 1주 40시간, 1일 8시간(휴게 제외) | [출처: 근로기준법 제50조] |
| 연장근로 한도 | 당사자 합의 시 1주 12시간 한도 → 주 최대 52시간. 위반 시 사업주 형사처벌 위험 [실무자 확인 필요: 벌칙 조항 번호·형량] | [출처: 근로기준법 제53조 제1항] |
| 가산수당 | 연장·야간(22시~06시)·휴일근로 통상임금의 50% 이상 가산(휴일 8시간 초과분은 가산율 상이) | [출처: 근로기준법 제56조] |
| 휴게 | 4시간당 30분, 8시간당 1시간 이상, 근로시간 도중 | [출처: 근로기준법 제54조] |
| 선택적 근로시간제 | 취업규칙 등에 위임 + 근로자대표 서면합의, 정산기간 1개월 이내(신상품·신기술 연구개발 업무는 3개월 이내) [실무자 확인 필요: 대상 업무·최신 개정] | [출처: 근로기준법 제52조] |
| 탄력적 근로시간제 | 2주 이내=취업규칙, 3개월 이내=근로자대표 서면합의, 3개월 초과 6개월 이내=서면합의+근로일별 근로시간 사전 통보 [실무자 확인 필요] | [출처: 근로기준법 제51조, 제51조의2] |
| 연차 발생 | 1년 80% 이상 출근 시 15일, 3년 이상 근속 시 2년마다 1일 가산(최대 25일), 1년 미만은 월 개근 시 1일 | [출처: 근로기준법 제60조] |
| 연차 사용 촉진(1년 이상 근속분) | ① 사용기간 만료 6개월 전 기준 10일 이내: 근로자별 미사용 일수 통보 + 사용 시기 지정 **서면** 촉구 → ② 근로자가 10일 이내 지정하지 않으면 만료 2개월 전까지 사용자가 시기를 정해 **서면** 통보 | [출처: 근로기준법 제61조 제1항] |
| 연차 사용 촉진(1년 미만분) | 사용기간 종료 3개월 전·1개월 전 기준으로 별도 시한 [실무자 확인 필요: 노무사/근태 담당자 크로스체크 요망] | [출처: 근로기준법 제61조 제2항] |
- 상시 5명 미만 사업장은 연장·가산수당·연차 규정 등이 적용되지 않거나 다르게 적용됩니다. 문항은 `employees >= 5` 조건으로 걸었습니다. [실무자 확인 필요: 적용 제외 조문 목록]
- 선택적·탄력적 근로시간제는 정산기간(단위기간) 기준으로 연장근로를 따지는 방식이 다르므로, 주 단위 52시간 확인과 별개로 정산 결과를 검증해야 합니다. [실무자 확인 필요]

## STEP 2. 근태·연차 관리 표준 가이드와 소통표
| 근태 관리 영역 | 법적 기준 및 한계선 설정 | HR-팀장 간 실무 대응 가이드 | 임직원 안내 및 설득 스크립트 |
|---|---|---|---|
| 연장근로 한도 | 주 52시간 상한. **내부 경보선**: 주 40·44·48시간 (내부 기준, 법정 아님) | 주 48시간 도달 시 HR이 팀장에게 알림 → 업무 재배분·인력 지원·마감 조정 요청, 52시간 도달 전 근무 중단 | "이번 주 누적 근무가 48시간에 가까워졌습니다. 건강과 법정 한도를 지키기 위해 남은 업무는 팀장과 우선순위를 정리해 주세요." |
| 사전 승인 | 연장·휴일근로 사전 결재, 사후 결재는 예외 사유 시만 | 승인 없는 근무도 실제 근로한 시간은 보상해야 하므로 '승인 안 했다'로 넘기지 말고 사전 승인 습관 안내 | "연장근무는 사전 신청해 주세요. 신청이 늦어도 실제 근무한 시간은 기록하고 보상합니다." |
| 포괄임금제 | 약정 시간 초과분은 별도 정산. 무제한 무급 야근 근거 불가 [실무자 확인 필요: 포괄임금제 유효 요건·최신 지침] | 팀장이 '포괄이니 야근해도 된다'고 말하지 않도록 교육 | "포괄임금은 약정한 시간까지 포함된 것이며, 그 이상 근무는 추가로 정산합니다." |
| 연차 촉진 | 법정 1·2차 **서면** 통보 시한, 근로자별 개별 기재, 수령 확인 | 촉진 발송 달력, 팀장에게 팀원 연차 사용 계획 협조 요청 | "휴식을 위해 남은 연차 사용 계획을 알려 주세요. 회사는 일정 조정을 최대한 지원합니다." |
| 연차 소진율 | 내부 목표 설정(법정 기준 아님) | 소진율 낮은 팀은 분기별 사용 계획 점검 | "연차 사용은 권리이자 업무 효율을 위한 재충전입니다." |

**팀장 협조 메일 예시 (야근·주말 연락 관리)**
> 제목: [협조 요청] 주 52시간 준수 및 근무시간 외 연락 관리
> 팀원의 이번 달 주별 근로시간 현황을 공유드립니다. 주 48시간을 넘긴 팀원은 우선순위 조정이 필요합니다. 근무시간 외·주말 업무 연락은 긴급 사안에 한하고, 사전 승인을 거쳐 주세요. 연차 사용 계획이 없는 팀원은 이번 달 안에 일정 협의를 부탁드립니다. 도움이 필요하시면 HR로 알려 주세요.

## STEP 3. 5대 문제점과 해결책
| # | 문제 | 해결책 |
|---|---|---|
| 1 | **포괄임금제 오해**로 무제한 공짜 야근 강요 | 약정 시간 초과분 별도 정산, 계약서에 기본급·고정 연장수당 구분 (LAB-031, 032) |
| 2 | **연차 촉진을 구두·메신저로만** 진행 | 서면 개별 통보와 수령 확인, 시한 달력 관리 (LAB-038~040) |
| 3 | **사후 결재 누락**으로 근로시간 기록 불일치 | 사전 승인 + 전자 기록 대조, 예외 사유 기록 (LAB-025, 026) |
| 4 | 주 52시간 **초과 임박을 사후에 발견** | 주 단위 경보·차단 장치 (LAB-024, 046) |
| 5 | **정산기간·단위기간 요건 미비**로 제도 효력 부정 | 서면합의·취업규칙 위임 규정 정비, 정산 결과 검증 (LAB-033~036) |

## STEP 4. 현장 실무 검증 (Red Team)
**연차 사용 촉진 서면 통보서 적법성 점검**
- [ ] 근로자 **개별**로 작성(전체 공지 아님), 근로자 성명·부서 기재
- [ ] 미사용 연차 일수가 근로자별로 정확히 기재됨
- [ ] 1차: 사용기간 만료 6개월 전 기준 10일 이내 발송, 사용 시기 지정 요청 문구 포함
- [ ] 2차: 만료 2개월 전까지 회사가 사용 시기를 정해 서면 통보
- [ ] 수령 확인(서명·전자 확인) 보관, 발송일·방법 기록
- [ ] 입사 1년 미만 근로자 별도 시한 적용 [실무자 확인 필요: 노무사/근태 담당자 크로스체크 요망]

**주 52시간 차단 시스템 운영 필수 체크리스트**
- [ ] 출퇴근·PC 로그 등 객관 기록, 3년 이상 보관
- [ ] 주 40·44·48시간 단계 경보와 담당자 지정
- [ ] 한도 도달 시 승인 절차(승인 없이는 근무 불가) 또는 접속 제한
- [ ] 선택적·탄력적 근로시간제 정산 결과 월 단위 점검
- [ ] 초과자 발생 시 원인 분석과 재발 방지 기록
