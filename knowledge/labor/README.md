# 노무 지식 노트 (HR 실무 지침 5종)

사용자가 제공한 HR 실무 지침 5종을 컨설턴트가 쓰기 좋게 정리한 노트입니다. 각 노트는 ① 법적 기준 요약 ② 절차표·소통표(표준 모델 예시) ③ 5대 실수와 예방책 ④ 현장 검증(Red Team) 체크리스트 ⑤ 체크리스트 문항 연결로 구성합니다. 진단 문항은 `checklists/labor/labor-diagnosis.json`(89문항)에 있습니다.

| 노트 | 주제 | 체크리스트 문항 |
|---|---|---|
| `01_work-rules-revision.md` | 불이익 변경 절차까지 챙기는 취업규칙 개정·신고 | LAB-006~021 |
| `02_attendance-leave.md` | 연장근로 위반을 막는 근태·연차 관리 | LAB-022~046 |
| `03_harassment-investigation.md` | 피해를 막는 직장 내 괴롭힘·성희롱 신고 조사 | LAB-047~062 |
| `04_discipline-dismissal.md` | 부당해고 판정을 피하는 징계·권고사직·해고 | LAB-063~079 |
| `05_hr-kpi-report.md` | 경영진 의사결정을 지원하는 HR KPI 보고 | LAB-080~089 |
| (공통) | 기본 노무 관리(근로계약서·임금·최저임금·장부) | LAB-001~005 |

## 읽을 때 주의
- **법령 기준은 작성 시점에 제가 아는 범위**입니다. 2026년 개정·고시 반영 여부는 확인하지 못했습니다. 모든 `[출처: …]` 표기는 `2026년 기준 확인 필요` 상태이며, 조문 번호와 숫자는 원문으로 대조한 뒤 `verified_at`을 채우세요.
- 불확실한 사안은 지침대로 `[실무자 확인 필요: 노무사/법무팀 크로스체크 요망]`으로 표시했습니다.
- 상시 근로자 수에 따라 적용 범위가 다릅니다. 취업규칙 신고·괴롭힘 규정은 상시 10명 이상, 연장·가산수당·연차·해고 제한 등은 상시 5명 이상 기준으로 문항 조건(`applies_if`)을 걸었습니다.
- 표의 "표준 모델 예시"는 입력이 없을 때 쓰는 가정 상황이며 실제 고객사 사실이 아닙니다.
- 면담 스크립트·통지문은 참고용 초안입니다. 실제 발송 전 노무사·법무팀이 검토해야 합니다.
