# 장부·증빙 관리와 부가가치세

> 체크리스트: ACC-001~018 · 출처 표기는 모두 `2026년 기준 확인 필요`

| 영역 | 기준 | 출처 |
|---|---|---|
| 기장 | 법인은 장부를 갖추고 복식부기로 거래를 기록 | [출처: 법인세법 제112조 / 회계 실무 일반] [실무자 확인 필요] |

| 매입세액 불공제 | 사업 무관 지출, 접대비 관련, 비영업용 소형승용차 관련 매입세액은 공제 불가 | [출처: 부가가치세법 제39조] [실무자 확인 필요] |

## 2. 월 마감 절차표와 직원 안내 (참고 예시)
| 단계 | 담당 행동 | 점검 기준 | 직원·대표 안내 문구 (예시) |
|---|---|---|---|
| 1. 증빙 수집 | 법인카드 내역, 세금계산서, 현금영수증, 계약서 모으기 | 건당 3만원 초과는 적격증빙 | "지출은 법인카드 또는 세금계산서로 처리해 주세요. 영수증은 월말 3일 전까지 제출해 주세요." |
| 2. 입력·대조 | 전표 입력, 증빙 첨부, 계정과목 확인 | 적요에 상대·목적 | "경조사비·접대비는 상대와 목적을 적어 주세요." |
| 3. 잔액 확인 | 은행 잔액, 채권·채무 잔액 대조 | 장부 잔액 = 실제 잔액 | (담당자 점검) |
| 4. 부가세 점검 | 매출·매입 세금계산서 합계표, 불공제 항목 분리 | 신고 매출 ≈ 손익 매출 | (담당자 점검) |
| 5. 월 보고 | 월 손익·자금 현황 한 장 | 부채·유동비율 포함 | "이번 달 손익과 자금 현황입니다." |

## 3. 5대 실수와 예방책
| # | 실수 | 문제 | 예방책 |
|---|---|---|---|
| 1 | **법인카드를 개인 지출에 사용** | 비용 부인, 가지급금·상여 처리 | 카드 사용 규정, 월별 내역 점검, 개인 지출 즉시 정리 (ACC-004) |
| 2 | **3만원 초과 지출에 적격증빙 미수취** | 가산세, 접대비 손금불산입 | 법인카드·전자세금계산서 기본화, 미수취 사유 기록 (ACC-002, 003) |
| 3 | **전자세금계산서 발급 지연·누락** | 가산세 | 월 마감에 발급 점검, 거래처별 발급 일정 (ACC-008) |
| 4 | **불공제 매입세액까지 공제** | 추징·가산세 | 불공제 항목 목록으로 신고 전 점검 (ACC-013) |
| 5 | **부가세 매출과 재무제표 매출 불일치** | 서류 불일치, 세무조사·탈락 사유 | 분기마다 대조표, 차이 사유 기록 (ACC-012, 028) |

## 4. 현장 실무 검증 (Red Team)
- [ ] 최근 3개월 법인카드 내역에서 개인 지출·휴일·심야 사용을 표본 점검했다
- [ ] 3만원 초과 지출 중 적격증빙이 없는 건이 있으면 사유와 대체 증빙을 정리했다
- [ ] 홈택스 매입 세금계산서와 거래 내역을 대조했다(실제 거래 없는 건 없음)
- [ ] 부가세 신고 과세표준과 손익계산서 매출의 차이를 설명하는 표가 있다
- [ ] 접대비·경조사비 증빙(청첩장, 참석자 기록)을 보관한다
- [ ] 영세율 거래가 있으면 증빙이 거래별로 보관돼 있다
- [ ] 업종·사업장·대표자 변경 후 사업자등록 정정을 했다
- 가산세율·한도·예외 요건은 해당 연도 기준을 확인하세요. [실무자 확인 필요: 세무사/회계사 크로스체크 요망]
