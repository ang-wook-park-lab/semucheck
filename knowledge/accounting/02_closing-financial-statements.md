# 결산·재무제표와 재무 리스크(신용 연계)

> 체크리스트: ACC-019~041 · 근거: 정책자금 도서 1부 7장(가결산·결산), 14부(재무제표 5대 위험 항목), 15부 69~73장(재무등급·분식 징후) + 회계 실무 일반
> 출처 표기는 모두 `2026년 기준 확인 필요`

## 1. 핵심 원칙 (도서 정리 내용)
- **가결산은 절세용이 아니라 신용등급·정책자금 관리 도구**입니다. 결산 전 조정 수단은 증자(자본 보강), 단기차입의 장기 전환, 매출채권 회수 앞당기기 등입니다.
- **재무제표 5대 위험 항목**(존재만으로 등급 하락): 가지급금 / 자본잠식 / 개발비 과대계상 / 가수금 / 영업이익 적자. 정리 우선순위: 즉시(가지급금→자본잠식) → 3개월(가수금 장기전환→개발비 비용처리) → 결산 전(영업이익 흑자화→부채비율 개선).
- 신평사는 동종·동규모 대비 상·하위 0~5% 항목에 경고를 표시합니다. **매출이 일정한데 특정 비용이 급증한 '광맥' 구간**은 세무조사 타깃이 되므로 비용은 일자형으로 일관되게 관리하세요(세무사 변경 해 특히 주의).
- 서류 간 숫자(가결산·신청서·재무제표·부가세 신고)가 맞지 않는 것이 탈락 사유 상위입니다.

## 3. 가결산·결산 일정표 (참고 예시)

|---|---|---|---|
| 10월 | 사전점검, 부채·유동비율 추정, 위험 신호 조기 발견 | 대상 항목 목록 작성 | ACC-019, 020 |

| 결산 후 | 재무제표 작성, 승인, 세금 신고 숫자 대조 | 정합성 점검 | ACC-021, 027, 028 |

## 4. 재무 리스크 항목 정리 순서
| 항목 | 의미 | 정리 방법 | 문항 |
|---|---|---|---|
| 가지급금 | 자금 유출·불투명성, 세무 리스크 | 상환, 급여·배당 활용(소득세 비교), 증자 | ACC-030~033 |
| 가수금 | 잠재 유동부채 | 장기차입 전환 또는 출자전환 | ACC-034 |
| 자본잠식 | 자기자본 < 자본금 | 증자·가수금 출자전환·이익 유보 | ACC-035 |
| 영업이익 적자 | 이자도 못 버는 구조 | 원가 개선, 비용 삭감 | ACC-036 |
| 개발비 과대 | 자산성 불명확 | 요건 점검, 비용 처리 전환 검토 | ACC-037 |
| 부채·유동비율, 이자보상 | 안정성·상환능력 | 증자, 차입 구조 조정 | ACC-038~040 |

## 5. 5대 실수와 예방책
| # | 실수 | 문제 | 예방책 |
|---|---|---|---|
| 1 | 결산 직전에 **몰아서 입력·조정** | 오류·분식 의심, 일정 지연 | 월 마감 + 분기 가결산 (ACC-001, 020) |
| 2 | **기간귀속 정리 누락**(선급·미지급 등) | 손익 왜곡, 세무조정 오류 | 결산 체크리스트 (ACC-027) |
| 3 | 장부 잔액과 **실제 잔액 불일치** | 분식·횡령 의심 | 은행·거래처 잔액 대조 (ACC-023) |
| 4 | **가지급금 방치** | 인정이자 과세, 등급 하락 | 정리 계획과 이행 (ACC-030~033) |
| 5 | **세금 신고 숫자와 재무제표 불일치** | 서류 불일치, 조사·탈락 | 대조표와 차이 설명 (ACC-028) |

## 6. 현장 실무 검증 (Red Team)
- [ ] 분기 가결산에서 부채비율·유동비율·영업이익을 확인하고 기록했다
- [ ] 은행 잔액증명과 장부 예금 잔액이 일치한다(차이 조정표 보관)
- [ ] 장기 미회수 채권·장기 재고 목록과 처리 계획이 있다
- [ ] 선급·미지급·미수·선수 정리 목록이 결산 체크리스트에 있다
- [ ] 가지급금·가수금 잔액표(상대·발생 일자·사유)가 있다
- [ ] 비용 항목별 월별 추이표를 보고 급변 사유를 설명할 수 있다
- [ ] 최근 3개 사업연도 비교식 재무제표를 바로 제출할 수 있다
- 세법상 한도와 요건은 해당 연도 기준으로 확인하세요. [실무자 확인 필요: 세무사/회계사 크로스체크 요망]
