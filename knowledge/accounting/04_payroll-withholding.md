# 원천세·급여·4대보험

> 체크리스트: ACC-054~061 · 출처 표기는 모두 `2026년 기준 확인 필요`
> 노무 쪽 급여·퇴직 항목은 `checklists/labor/`(LAB-003 임금 지급 등)와 함께 보세요.

## 1. 법적 기준 요약
| 영역 | 기준 | 출처 |
|---|---|---|
| 원천징수 신고·납부 | 지급일이 속하는 달의 다음 달 10일까지. 일정 요건의 소규모 사업장은 반기납부 특례 | [출처: 소득세법 제128조] [실무자 확인 필요: 반기납부 요건·기한] |
| 지급명세서 | 근로·사업·기타소득 등 소득 종류별 제출 기한과 주기. 불성실 시 가산세 | [출처: 소득세법 제164조, 제164조의3] [실무자 확인 필요: 연도별 주기] |
| 연말정산 | 다음 해 2월분 급여 지급 때 정산, 근로소득 지급명세서 3월 10일까지 | [출처: 소득세법 제137조, 제164조] [실무자 확인 필요] |
| 퇴직소득 | 퇴직금 지급 시 퇴직소득세 원천징수, 퇴직연금 계좌 이전 시 과세 이연 | [출처: 소득세법 제128조, 제146조] [실무자 확인 필요] |
| 비과세 | 식대·차량보조금 등 비과세 항목은 한도와 요건 충족 필요 | [출처: 소득세법 제12조, 시행령 제17조의2] [실무자 확인 필요: 연도별 한도] |
| 4대보험 | 보수총액 신고와 정산(건강보험 3월, 고용·산재 3월 중순). 체납은 정책자금 결격 | [출처: 각 보험 징수 관련 법령] [실무자 확인 필요: 기한] |
- 프리랜서(사업소득 3.3%)가 실질적으로 근로자로 인정되면 4대보험·퇴직금·가산세 문제가 생길 수 있습니다(지휘·감독, 근무시간 통제, 전속성이 판단 요소). [실무자 확인 필요: 노무사/세무사 크로스체크 요망]

## 2. 월 급여 마감 절차표 (참고 예시)
| 단계 | 행동 | 점검 | 문항 |
|---|---|---|---|
| 1 | 근태 확정, 급여 계산 | 연장·야간·휴일 수당 반영 (노무 LAB-028) | — |
| 2 | 급여대장 작성, 비과세 구분 | 비과세 한도·증빙 | ACC-061 |
| 3 | 원천세·4대보험 신고 금액 산출 | 급여대장 ↔ 신고 금액 일치 | ACC-060 |

| 연 1회 | 연말정산, 보수총액 신고 | 2월분 급여 정산, 3월 신고 | ACC-056, 059 |

## 3. 5대 실수와 예방책
| # | 실수 | 문제 | 예방책 |
|---|---|---|---|
| 1 | **원천세 신고·납부 지연** | 가산세, 체납 시 정책자금 결격 | 달력 관리, 자동이체 점검 (ACC-054) |
| 2 | **급여대장·보험·원천세 금액 불일치** | 신고 오류, 4대보험 정산 추징 | 월 마감 때 대조 (ACC-060) |
| 3 | **비과세 한도·요건 위반** | 추징 | 규정과 증빙, 한도 점검 (ACC-061) |
| 4 | **프리랜서 3.3% 처리 후 근로자성 문제** | 4대보험·퇴직금·가산세 소급 | 계약·근무 방식 점검 (ACC-057) |
| 5 | **지급명세서 제출 주기를 잘못 알고 누락** | 가산세 | 소득별 제출 주기표 (ACC-055) |

## 4. 현장 실무 검증 (Red Team)
- [ ] 최근 6개월 원천세 신고·납부일이 기한 안이다
- [ ] 급여대장 합계 = 원천세 신고 급여 = 4대보험 보수월액 합계(차이 설명 가능)
- [ ] 4대보험 가입 인원과 실제 근무 인원이 일치한다
- [ ] 비과세 항목별 규정·증빙·한도 점검표가 있다
- [ ] 외주·프리랜서 목록과 계약 형태, 근로자성 점검 결과가 있다
- [ ] 퇴직금 지급 건의 퇴직소득세 원천징수와 연금계좌 이전 기록이 있다
- [ ] 연말정산·지급명세서 제출 증빙이 있다
- 제출 주기와 한도는 해당 연도 기준을 확인하세요. [실무자 확인 필요: 세무사/노무사 크로스체크 요망]
