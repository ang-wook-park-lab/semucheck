# 창업진단 기준 정리 (창업의 정의: 창업지원법 vs 세법)

`checklists/startup/startup-diagnosis.json`(34문항)과 `web/src/lib/startup.ts`(판정 로직)의 근거 메모입니다. **모든 내용은 초안이며, 조문 원문 확인 전 참고용입니다.** 확인하지 못한 부분은 `[실무자 확인 필요]`로 표시했습니다.

## 1. 정책자금·창업지원사업 (중소기업창업 지원법·시행령)
출처: 정책자금 도서 2부 8장 정리(시행령 2024.7.10. 개정, 대통령령 제34657호) — `knowledge/policy-fund/kms-integrated/02_part2_startup.md`

창업으로 보지 않는 6가지(하나라도 해당하면 창업 아님)
1. 타인으로부터 사업을 상속·증여받아 동종 사업 개시(이종 전환은 인정)
2. 기존 개인사업을 유지하면서 동종 법인 신설: 지분 30% 이상 또는 최대주주면 창업 아님(30% 미만이고 최대주주 아니면 인정)
3. 폐업 후 동종 사업 재개: 폐업 3년 이내(부도·파산 2년 이내)
4. 법인이 발행주식 50% 초과(임원 소유 합산) 자회사를 설립
5. 기존 법인의 과점주주가 새 법인의 과점주주가 되어 사업 개시(국세기본법 제39조 특수관계인 합산, 2024.7.10. 개정)
6. 조직변경(주식회사↔유한회사 등)으로 동종 사업 계속

그 밖: 동종 판단은 표준산업분류(10차) 세세분류 5자리 일치 / 업력 기산일은 법인설립등기일·개인 개업일 / 개인 → 법인 전환 시 업력은 개인 개업일부터 / 창업기업은 창업 후 7년 이내.
> 합병·분할·사업양수·현물출자 승계, 분사(스핀오프)의 창업지원법상 취급은 책 정리 6가지에 없어 **"추가 확인"**으로 처리했습니다.

## 2. 세법 (조세특례제한법 제6조, 같은 법 시행령 제5조)
출처: 법령 일반 지식과 세무 자료 검색(블로그·유권해석 요약). **조문 원문은 확인하지 못했습니다.**

- 창업으로 보지 않는 경우(요지): 합병·분할·현물출자·사업 양수로 종전 사업을 승계 / 개인사업을 법인으로 전환하며 사업용 자산의 50% 이상 승계 / 폐업 후 같은 종류의 사업을 다시 개시 / 사업의 확장·업종 추가 / 상속·증여 승계
- 폐업 후 재개의 **기간 기준**과 법인전환의 **승계 비율 기준**은 해석이 갈릴 수 있어 `[실무자 확인 필요]`로 표시했습니다.
- 지원법과 달리 세법에는 "기존 법인 과점주주" 규정과 "개인사업 유지 + 법인 신설 지분 30%" 기준이 없고, **승계·확장 여부를 실질**(장소·설비·인력·거래처)로 판단합니다.
- 감면 대상 업종이 열거되어 있어(제조업, 건설업, 정보통신업, 통신판매업, 음식점업, 전문·과학·기술서비스업 등) 창업에 해당해도 업종 때문에 감면이 안 될 수 있습니다. 부동산업·임대업·소비성 서비스업·(통신판매업 제외) 도소매업은 제외로 알려져 있습니다.
- 감면기간: 최초 소득 발생 과세연도부터 5년.

## 3. 청년·과밀억제권역·감면율(참고)
- 청년: 만 15세 이상 34세 이하, 군 복무 기간은 최대 6년까지 나이에서 제외(법인은 대표자 지분 요건 등 `[확인 필요]`). 청년 전용 정책자금은 공고별로 만 39세 이하·업력 3년 미만이 일반적입니다.
- 수도권과밀억제권역(수도권정비계획법 제6조·시행령 별표 1): 서울 전역, 인천(강화·옹진·경제자유구역·남동국가산단 등 제외), 경기 의정부·구리·하남·고양·수원·성남·안양·부천·광명·과천·의왕·군포, 시흥(반월특수지역 제외), 남양주(일부 동). 2026년 개정으로 구분이 바뀌었다는 자료가 있어 확인이 필요합니다.
- 감면율(참고, 확정 아님): 2025년 이전 창업 — 청년 과밀억제권역 밖 100% / 안 50%, 일반 창업 과밀억제권역 밖 50% / 안 감면 제외. 2026년 이후 창업 — 청년: 과밀억제권역 50%, 수도권 그 밖 75%, 수도권 밖 100%로 알려져 있으나, 일반 창업 감면율(25% vs 50%)과 연간 감면 한도(5억 원) 등은 자료마다 달라 **조문 원문 확인 필요**. 이 값은 화면에도 모두 `[확인 필요]`로 표시됩니다.

## 4. 사례별 정리 (진단 화면의 질문 순서와 같음)
| 사례 | 정책자금(창업지원법) | 세법 |
|---|---|---|
| 개인사업 유지 + 동종 법인 신설 | 대표자 지분 30% 이상·최대주주면 창업 아님 | 지분 기준 없음. 같은 장소이거나 설비·인력·거래처를 이어받으면 확장·승계 |
| 개인사업 폐업 후 동종 법인 설립 | 3년(부도·파산 2년) 이내면 창업 아님 | 동종 재개는 창업 아님(기간 기준 약함) |
| 폐업 후 사업 양도 | 대표자가 동종 재개하면 폐업 후 재개와 같음 | 양수인은 사업 양수=승계 |
| 개인 → 법인 전환 | 업력은 개인 개업일부터, 포괄이전 시 창업 지위 승계 | 사업용 자산 50% 이상 승계 시 창업 아님 |
| 장소를 달리함 | 동종이면 장소와 무관하게 판단 | 장소만 달라서는 부족, 승계 여부로 실질 판단 |
| 기존 법인 주주 | 과점주주(합산 50% 초과)가 신규 법인의 과점주주면 창업 아님 | 주주 규정 없음 |
