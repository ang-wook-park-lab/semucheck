# 15부: 기업등급 완전해부 (69~73장)

> 올려주신 PDF는 책 319쪽(73장 7절)에서 끝남. **16부(74 실전 사례, 75 경영분석 제안서, 76 법인 기업일반관리)와 부록 A~D(로드맵, 인증·연구조직 사전점검 체크리스트, 기관별 온라인 신청 경로, 용어 사전)는 미수록** → 추가로 올려주시면 보완

## 개요
- **기업등급 = 재무 70% + 비재무 25% + 기술 5%**
  - 재무: 효과 가장 크지만 시간 필요(0~6개월)
  - 비재무: **사업현황서 작성 방식**으로 비교적 빠르게 개선
  - 기술: 벤처(60일)·연구전담부서(15일)로 확실히 채움, BBB와 BB 경계를 넘게 해주기도
- **결산의 4가지 목적**: 세무(세무조정계산서) / 신용등급(재무제표증명원 → 신평사) / 여신(은행 여신심사) / 정책자금(중진공·소진공 기업평가)
- **같은 부채비율 110%의 3가지 판정**: 신용평가(건설업 업종평균 64% 기준) 감점 / 은행 여신(200%) 양호 / 중진공 융자제한(건설 369~404%, 책) 무관
- **자금조달 3층 구조(순서 필수)**: 1층 신용(BB- 진입) → 2층 특허(특허담보 최대 5억) → 3층 인증(혁신자금, 매출 100% 한도). 2층 없이 3층 불가
- **산업분류코드 ≠ 업종분류코드**: 국세청만 업종분류코드, 지원기관은 산업분류코드. 예) 나사볼트 → 첨단산업 코드면 융자제한 340%→460%(책)
- 담보 배치: 공장 = 기업은행·산업은행, 지역 농지 = 지역 농협, 주택·빌라 = 저축은행
- 신보 CCRS 등급 상향 요소: 자본금 증자, 수출 50% 이상, 자가 사업장, 매출채권보험 → 일반 30억 → 최고 70억
- 신보 운전자금 보증 = 매출의 1/3~1/6

## 69장. 기업등급 3요소

| 영역 | 비중 | 항목 | 개선 |
|---|---|---|---|
| 재무(재무제표) | 70% | 현금흐름, 매출액증가율, 영업이익률, 부채비율, 이자보상배율, 매출채권회전율 등 | 가결산 조정·불량 항목 정리(0~6개월) |
| 비재무(사업현황서) | 25% | 대표 신용등급, 대표 자산, 대표 이력, 주주현황, 매출처·매입처, 노조, 위치, 추정재무제표, 비전 | 대표 신용 관리, 사업현황서 보강 |
| 기술 | 5% | TCB, 특허·실용신안, 이노비즈, 벤처, 연구소 | 인증·특허로 단기 상승 |

| 등급 | 의미 |
|---|---|
| AAA~A | 최우량~우량 (대형은행 최우대) |
| BBB | 양호 (대부분 정책자금) |
| BB | 보통 (정책자금 기본 접근선, 기보·신보·중진공) |
| B~CCC | 주의~취약 (조건부·제한) |
| D | 부도·불량 (불가) |
| NR | 평가 불가 |

### 비재무 관리
| 항목 | 포인트 | 관리 |
|---|---|---|
| 대표 신용 | 기업 평가에 직접 반영 | 연체 없음, 카드 기한, 개인 부채 |
| 대표 자산 | 잠재력 | 담보 자산 목록, 감정가 업데이트 |
| 대표 이력 | 지속가능성 | 이력서, 업종 경험 |
| 주주현황 | 특수관계 거래 | 주주명부, 지분 변동 이력 |
| 매출처·매입처 | 다양성·집중도·신용 | 상위 거래처 계약·이력, 신규 확보 |
| 노조 | 노사 안정성 | 노사 협약 현황 |
| 사업장 | 접근성·공단·임차/자가 | 공단·자가 강조 |
| 추정재무·비전 | 성장계획 현실성 | 매출목표·투자계획 수치화 |
- 비재무 감점이 있으면 재무를 올려도 등급 정체 → 비재무 먼저

## 70장. 재무등급 15개 지표

| 영역 | 지표 | 산식 | 기준·포인트 |
|---|---|---|---|
| 성장성 | 총자산증가율 | (당기말−전기말)/전기말 | 양수, 과도한 부채 수반 주의 |
| 성장성 | **매출액증가율** | (당기−전기)/전기 | 10% 이상 양호, **부가세 신고액과 일치** |
| 성장성 | 순이익증가율 | | 절세로 이익 줄이면 하락 |
| 성장성 | 유동자산증가율 | | 유동성 개선 신호 |
| 성장성 | 자기자본증가율 | | 이익 유보·증자 |
| 수익성 | 총자산순이익률(ROA) | 순이익/총자산×100 | 3% 이상 양호 |
| 수익성 | 자기자본순이익률(ROE) | 순이익/자기자본×100 | 10% 이상 양호 |
| 수익성 | 매출액영업이익률 | 영업이익/매출×100 | 업종 평균 이상, **전년 대비 2%p 이상 하락 시 주의** |
| 수익성 | 매출액순이익률 | 순이익/매출×100 | 양수 유지 |
| 수익성 | **이자보상배율** | 영업이익/이자비용 | 3배 이상 안정, **1배 미만 위험** |
| 안정성 | 유동비율 | 유동자산/유동부채×100 | 150% 이상 안정, 100% 미만 주의 |
| 안정성 | 당좌비율 | 당좌자산/유동부채×100 | 100% 이상 양호 |
| 안정성 | **부채비율** | 부채/자기자본×100 | **200% 이하**(특허 자본화로 개선 가능) |
| 안정성 | 차입금의존도 | (단기+장기차입금+사채)/총자산×100 | 30% 이하 안정, 초과 시 위험 |
| 안정성 | 자기자본비율 | 자기자본/총자산×100 | 40% 이상 양호 |
| 활동성 | 총자산회전율 | 매출/총자산 | 높을수록 효율 |
| 활동성 | 매출채권회전율 | 매출/매출채권 | 낮으면 자금난 위험 → 팩토링 |
| 활동성 | 재고자산회전율 | 매출/재고 | 낮으면 과잉 재고 → 동산담보 |
| 활동성 | 유형자산회전율 | 매출/유형자산 | 설비 과잉 시 낮음 |
| 생산성 | 부가가치율 | 부가가치/매출 | 업종별, 인건비·재료비 비율 |
- **즉시 위험 신호: 이자보상배율 1 미만, 자본잠식, 매출 30% 이상 감소**

### 재무제표 5대 위험 항목
| 항목 | 본질 | 해결 |
|---|---|---|
| 개발비(무형자산) 과대계상 | 허수 자산 | 효익 불확실 시 비용처리·상각 |
| 가수금 | 잠재 유동부채 | 장기차입금 전환 또는 출자전환(DES) |
| **가지급금** | 자금 유출, 불투명성 | 급여·배당·상환으로 즉시 정리 |
| **자본잠식** | 기술적 파산 | 증자, 이익 유보 |
| 영업이익 적자 | 이자도 못 버는 구조 | 원가 개선, 비용 삭감, 가결산 |
- 정리 우선순위: **즉시**(가지급금 → 자본잠식) / **3개월**(가수금 장기전환 → 개발비 비용처리) / **결산 전**(영업이익 흑자 → 부채비율 200% 이하) — 세무사 사전 협의 필수

## 71장. 신용대출 vs 담보대출

### 신용대출 4대 요소
기업등급(재무·비재무·기술) / 매출 추이(부가세 = 재무제표) / 대표자(신용·자산·이력·주주) / 기술등급(TCB·특허·인증)

### 담보
| 구분 | 종류 | 조건 |
|---|---|---|
| 우량 | 아파트, 공장, 오피스텔, 창고 | 높은 LTV, 낮은 금리 |
| 비우량 | 주택·빌라, 농지, 임야 | 낮은 LTV, 일부 거절 |

| 담보 | 최적 기관 |
|---|---|
| 공장·제조시설 | 기업은행·산업은행·지방은행 |
| 아파트·오피스텔 | 모든 시중은행 |
| 지역 농지·임야 | 지역 농협·지방은행 |
| 창고·잡종지 | 기업은행·지방은행 |
| 주택·빌라 | 저축은행·2금융 |

- 조합 전략: **신용(보증서) 먼저, 담보 나중** / 기관별 분산 배치(담보 재배치) / 신보 CCRS 상향 4요소
- LTV 예(책): 아파트 시가 5억 1금융 70% = 3.5억(기존 근저당 1억 차감 → 2.5억) / 공장 10억 기업은행 70% = 7억, 일반 시중 50% / 지역 농지 3억 농협 60% vs 시중 30~40% / 오피스텔 주거용·업무용 구분
- **기존 근저당 등기부등본으로 먼저 확인**, 채권최고액 합산해 실제 가용 담보 계산

## 72장. 금융기관 3분류

| 구분 | 기관 | 역할 | 심사 언어 |
|---|---|---|---|
| 정책기관 | 중진공, 산은, 지자체, 한은, R&D 기관 | 정책 목적 직접 지원 | 정책부합성·성장가능성 |
| 보증기관 | 신보, 기보, 지역신보, 무역보험, 농신보 | 신용 보완 | 기술성·신용·매출 안정성 |
| 금융기관 | 시중은행, 지방은행·농협·수협 | 실행·회수 | 상환능력·재무안정·담보 |
- 세 축 동시 활용 시 단일 기관 한도의 3~4배
- **첫 접촉 순서**: ①신재(첫 보증 이력) → ②기보(특허·연구소·인증 시 TCB) → ③중진공 → ④신보(연초 조기, 협약보증) → ⑤한은 온렌딩(BB 이상 후)

### 신보 보증 5단계
1. 상담신청(재무제표·사업자등록증·완납증명 준비)
2. 신용조사(등기·국세·금융정보, 현장조사 / 주주명부·임대차계약서, **국세자료 문서발급번호** 통지)
3. 보증심사(3년 미만 SBI, 3년 이상 CCRS 등급 → 상향요소 서류 제출)
4. 약정·실행(보증서 받으면 **복수 은행 조건 비교**)
5. 사후관리(만기 3개월 전 갱신·증액 검토, 매출 증가 자료 준비)

### CCRS 조정 사유
- 상향: 자본금 증자 / 수출 50% 이상 / 5년 미만 기업 매출·수익 호전 예상 / 최근 1년 내 자가사업장 / 하도급거래 우수기업 / 결산 후 수주 급증 / 매출채권보험(업력 3년+)
- 하향: 누락 지급어음·차입금 감안 시 완전자본잠식 / 주요 거래처·관계사 도산 / **가지급금·가수금 보유** / 영업이익·순이익 결손 / 하도급 불공정 통지

### 신보 한도 3단 구조
| 유형 | 내용 |
|---|---|
| 일반보증 | 신보+기보 합산 30억(투자 합 60억 초과 불가), 신용취약 15억 |
| 최고보증 | 70억(신보+기보 합 100억 초과 불가): 시설·무역금융·구매자금·전자상거래·이행보증 |
| 운전자금 | **최근 1년 매출의 1/3~1/6**과 자기자본 300% 중 적은 금액 |

### 신보·기보 한도 소진 후 → 지역 신용보증재단
- 도·시 자금은 관할 재단 평가·배정, 이차보전 약 2%(한도 5억), 단점은 분할상환
- 서울·경기 재단은 은행 경유 접수 안 받음 → 대표 직접 교육 후 진행
- 협약보증(책): 경기신보+TCB+신한 / **경기신보+하나 특례 8억** / 서울신보+기술기업+신한 / 서울신보+하나 특례 8억

## 73장. 결산·신용·특허·인증 연결 구조

| 결산 목적 | 자료·기관 | 포인트 |
|---|---|---|
| 세금 신고 | 세무조정계산서 → 국세청 | 대표가 아는 유일한 목적 |
| 신용등급 | **재무제표증명원** → NICE·KED·이크레더블 | 절세와 반대(이익 남겨야) |
| 여신 | 은행 여신심사팀(현금주의, 미래 현금흐름) | 은행별 방식 다름 |
| 정책자금 | 중진공·소진공(성장성·정책부합성) | 부채비율 기준 셋 다 다름 |
- 세무조정계산서 = 가공품(병맥주), **재무제표증명원 = 원본(생맥주)**. 신평사·은행은 재무제표증명원을 봄 → 방치 시 금리↑·한도↓
- 3층 구조: 1층 신용(결산·가지급금·부채비율·이자보상) → 2층 특허(등록 후 3년 이내 가치특허, 특허담보 최대 5억, 직무발명보상, 7년+ 기업 '보톡스 효과') → 3층 인증(이노비즈·메인비즈·벤처·연구소·직무발명 → **혁신자금 = 매출 40% + 특허 30% + 신용 30% = 최대 매출 100%**)
- 산업분류코드 확인: 공장등록증·은행 대출 서류·크레탑·중진공 서류 비교(제조업은 불일치 많음)

### 분식 징후·세무조사
- 신평사는 동종·동규모 대비 상·하위 0~5% 항목에 경고 표시 → 세무조사·감점
- 문제 항목: 감가상각비 몰아서·안 하기, 접대비·복리후생비·소모품비 연도별 급변
- 매출 일정한데 특정 비용 급증 구간('광맥') → 세무조사 타깃. 세무담당·세무사 변경 해에 주의 → **비용을 일자형으로 일관 관리**

### 세무사 vs 컨설턴트
| 영역 | 세무사 | 컨설턴트 추가 |

| 재무 | 재무제표증명원 발급 | 신용등급 관리, 재무비율 조정, 산업분류코드 최적화, 여신평가 대응, 정책자금 우선도, 특허·인증, 보조사업 탐색 |
