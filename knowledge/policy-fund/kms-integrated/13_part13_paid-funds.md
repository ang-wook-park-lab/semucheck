# 13부: 유상자금 로드맵과 조달형태 (60~62장)

## 60장. 유상자금 4개 레이어
| 레이어 | 내용 |
|---|---|
| 1 중진공 직접자금 | 창업운전 → 투융자(이익공유형) → 고성장촉진(연 30% 성장) → 미래기술육성 → 스케일업금융 (현재 단계에 직접 진입 가능, 이전 수혜는 실적) |
| 2 보증기관·은행 연계 | 신성장기반(7년+), 중소기업육성자금, 지역신보 육성자금, 기보·신보 보증(BB- 이상 또는 T4 이상) |
| 3 온렌딩 | C1(BB 이상), C2(벤처·이노비즈 + 기술혁신, 더 낮은 금리), 산은 온렌딩(BB+ 이상) |
| 4 R&D·소상공인 특화 | 창업성장과제, R&D 연계 운전자금, 소상공인 특화, 수출채권보험, 보증 기반 P-CBO |
- **순서**: 중진공 직접대출 먼저 → 실적 → 보증기관에서 '관리되는 기업' 인정. 보증 먼저면 중진공 심사에서 차입 규모가 커 보임
- R&D·소상공인 레이어는 독립적(부채비율·신용 영향 없음), R&D 이력이 TCB 가점 → 보증 한도 상승
- 온렌딩 진입 전 BB 미달이면 탈락 이력만 남음 → 가결산으로 BB 달성 시점 예측
- 빈 칸을 채워 가면 **같은 신용으로 조달 규모 2~3배**

## 61장. 5대 조달형태

| 항목 | 은행권 | 보증기관 | 국책은행 온렌딩 | 회사채 | 투자 |
|---|---|---|---|---|---|
| 상환 | 있음 | 있음 | 있음 | 있음 | 없음(지분) |
| 금리 | 중~고 | 중 | 낮음 | 중 | 없음 |
| 담보 | 담보 또는 신용 | 불필요(보증서) | 불필요 | 불필요 | 불필요 |
| 상환 압박 | 높음 | 중 | 높음(2년 거치·3년 상환) | 중(만기) | 없음 |
| 지분 희석 | 없음 | 없음 | 없음 | 일부(CB·BW) | 있음 |
| 심사 핵심 | 신용·매출·담보 | 인증·TCB | BB 이상 | 기업 신용도 | 팀·기술·시장 |

### 은행권
- 신용대출(TCB + 대표 신용, 한도 낮음), 부동산 담보, 설비 담보(설비가 80%까지), 동산(재고) 담보, **매출채권(팩토링)**, 차량할부, 구매자금
- 은행 심사 3대 지표: **TCB 등급, 대표자 신용등급, 매출 추이(부가세 신고액)**

### 보증기관 (업력 7년 이내 주력)
- **신보는 자금 소진 가장 빠름 → 1월 첫째 주 신청**
- 기보는 인증 있을수록 유리 → 인증 먼저
- 중진공은 현장평가가 핵심
- 신재는 한도 낮지만(최고 1억 수준) 첫 보증 시작점

### 온렌딩 (7년+ 핵심)
- **2년 거치 후 3년 상환** → 3~5년차 원금 상환 압박이 가장 큰 리스크, 차입 시 상환 계획 먼저

### 회사채
- 일반사채(중소기업 단독 발행 어려움) / BW(채권+신주인수권, 지분 희석 가능) / CB(전환사채, 투자 연계) / P-CBO(보증기관 기반 유동화)
- 중소기업 현실적 방법: VC·전략적 투자자 대상 CB·BW

### 투자
- 엔젤(수천만~수억) / VC(수억~수십억, 이사회 참여) / 인베스트먼트·캐피탈 / PEF(수십억+, 경영권 이슈) / 신보·기보·중진공 연계투자(이익공유형)
- 핵심: 회사 잠재력 대비 **합리적 기업가치** 산정

## 62장. 상황별 선택

| 상황 | 최적 | 이유 |
|---|---|---|
| 담보·신용 부족 창업 초기 | 보증기관(기보·신보) | 기술·인증으로 진입 |
| 빠른 현금 필요 | 팩토링, 긴급경영안정 | 채권 기반 즉시 유동성 |
| 대규모 설비 투자 | 중진공 시설 + 보증 | 저금리·장기 |
| 신용등급 BB 이상 | 온렌딩(C1·C2) | 최저금리 |
| 고성장·대규모 수요 | 스케일업금융 + 투자 | |
| 지분 희석 없이 큰 자금 | CB·BW 또는 국책은행 | |
| R&D 성과 사업화 | 미래기술육성 + R&D 과제 | |

### 포트폴리오 (책)
| 단계 | 조합 | 규모 | 조건 |
|---|---|---|---|
| 창업기 | 중진공 창업운전 + 기보 기술보증 + 예창패 | 무상 1억 + 유상 2~3억 = 3~4억 | 7년 이내, 연구소·전담부서, 특허 1건+ |
| 성장기 | 중진공 신성장기반(시설) + 신보 장기보증(운전) + C1 온렌딩 | 25~35억 | 7년+, BB 이상, 이노비즈 또는 벤처 |
| 스케일업 | 스케일업금융 + 산은 온렌딩 + CB·BW + 투자 | 수십~수백억 | BB+ 이상, 매출 100억+, 상장·글로벌 계획 |

### 포트폴리오 설계 3대 확인
1. **총 부채비율 200% 초과 여부** 사전 시뮬레이션
2. **상환 스케줄 중첩**(거치 종료 시점이 겹치면 한꺼번에 압박) → 시차 설계
3. **중복 담보** 금지

### 소상공인 자금의 한계
- 상시 5인 미만(일부 10인), 최고 1억 내외, 저금리, 유흥·사행 제외
- 성장하면 졸업 → 소상공인 단계에서 신용 이력 쌓고 **법인화·규모화로 기보·신보·중진공 진입 설계**
