# 부록 A~D: 로드맵·인증 사전점검·신청 경로·용어 사전 (책 339~358쪽)

> 책 문장을 옮기지 않고 진단에 쓰는 기준·구조만 정리. 인증 요건·점수는 **2026년 책 기준** — 신청 전 각 시스템의 최신 공고 확인(책 본문도 같은 단서를 붙임). 스캔 OCR 판독이므로 불확실한 곳은 `[확인 필요]`.

## 부록 A. 창업·성장 단계별 자금조달·인증 준비 로드맵

| 업력 | 신용관리 목표 | 주요 자금지원 | 인증·연구조직 | 핵심 과제 |
|---|---|---|---|---|
| 0~1년 | 대표자 신용·거래이력 관리 | 예비창업패키지·소상공인 정책자금·지역신보 보증 | 중소기업확인서·사업자 기본서류 정비 | 법인설립·업종코드·대표자 신용 관리 |
| 1~2년 | 기업 신용평가 기초자료 구축 | 기보·신보 창업보증, 지역신보 보증, 신재, 소진공·중진공 창업성장 자금 | 연구전담부서, 벤처기업 확인 검토 | 4대보험·세금 완납, 금융거래 이력 구축 |
| 2~4년 | **B+~BB- 이상 진입 목표** | 기보·신보, 신재 보증, 중진공 창업자금·운전자금·시설자금 | 벤처·연구전담부서, 기업부설연구소 | 특허·상표, 연구조직, 출원·벤처, 이노비즈 준비 |
| 4~7년 | **BB권 이상 안정화** | 기보·신보 보증 확대, 중진공 신성장자금 | 이노비즈·연구소·메인비즈, ISO | R&D 과제·수출 연계, 시설투자 |
| 7년+ | **BB+ 이상 또는 우량등급 관리** | 산업은행 온렌딩·수출금융·투자유치 검토 | 이노비즈 갱신·메인비즈·ISO·소부장·뿌리·IP | 승계, M&A, 글로벌 진출, 투자유치, 상장 검토 |

- 단서(책): 로드맵은 업력 기준의 기본형. 실제 전략은 매출·영업이익·부채비율·신용등급·고용인원·기술개발 실적·인증·**세금 체납 여부**를 함께 봐야 함. 정책자금·보증 한도는 재무상태·상환능력에 따라 달라지므로 재무제표·4대보험·세금납부·금융거래·연구개발·인증자료를 평소 체계적으로 관리
- 진단 연결: 업력 구간 ↔ 신용등급 목표(BB- → BB → BB+)는 `fund-diagnosis.json`의 성장단계 문항·등급 신호등과 맞출 수 있는 기준표

## 부록 B. 주요 인증·연구조직 사전 점검 체크리스트

### 1. 벤처기업 확인(연구개발유형)
- **기본요건**: 중소기업기본법상 중소기업 / 신청불가 업종 아님 / 기업부설연구소·연구개발전담부서·기업부설창작연구소·기업창작전담부서 중 하나 이상 보유 / 확인 요청일이 속한 분기의 **직전 4개 분기 연구개발비 5천만원 이상** / 같은 기간 **매출액 대비 연구개발비 5% 이상** / **창업 3년 미만은 비율 요건 면제**
- **준비서류**: 사업계획서(또는 시스템 온라인 작성 자료), 중소기업확인서, 사업자등록증, 법인등기부등본, 부가세과세표준증명원, 최근 재무제표·감사보고서, 매출원장, 고용보험 사업장 취득자 명부, 4대보험 가입자 명부, 연구개발조직 인정서·소속 인력 현황, 인건비 산정내역서, 인건비 외 개발비용 산정내역서, 연구개발비 지출 증빙, 자체·위탁·공동개발 증빙, 주주명부, 대표자 경력·수상·특허·인증·수출실적
- **보완 포인트**: 연구개발비 금액만 맞추면 통과되는 구조가 아님 → 연구조직 실체·인력 적정성·연구개발비 산정 타당성·사업 성장성이 함께 평가됨. 연구과제명·목표·수행인력·지출내역·사업화 계획이 서로 연결되게 정리. **장부상 금액과 산정내역 일치**, 인건비·재료비·외주·위탁이 실제 연구개발과 직접 관련됨을 설명

### 2. 이노비즈
- 대상: 업력 3년 이상 기술혁신형 중소기업(기술기반 제조업·IT·SW·소재부품장비·R&D 중심)
- **합격 기준(책 기준)**: 온라인 자가진단 기술혁신시스템 1,000점 만점 중 **650점 이상** / 기술보증기금 현장평가 **700점 이상** / 개별기술수준 14등급 중 **B등급 이상** / 평가분야 4개(기술혁신능력·기술사업화능력·기술혁신경영능력·기술혁신성과) / 유효기간 3년, 만료 전 갱신 심사
- 점검 영역: ① 기본요건(업력·업종·입증자료) ② 기술혁신 활동(3년간 R&D 투자·매출 대비 비율, 전담조직, 개발 단계 구분, 로드맵, 기술보호·보안·지재권 관리) ③ 기술개발 성과(특허·실용신안·디자인·상표·프로그램 등록, 정부 R&D 이력, 신제품·공정개선, 인증, 매출 연결 사례) ④ 기술사업화 역량(목표시장·고객, 경쟁제품 대비 차별성, 가격·품질·납기·서비스 경쟁력, 수주·납품·수출 실적, 투자계획) ⑤ 혁신경영시스템(ISO 9001 등, ERP·MES·SCM·그룹웨어, 프로세스 문서화, 기술인력 비율·핵심인력, 3년 매출·고용·수익성·수출 변화)
- **보완 포인트**: "특허 보유"보다 **"그 특허가 어떤 제품에 적용되어 어떤 고객에게 팔렸고 어느 시장으로 확장 가능한가"**. 현장평가는 문서화 수준(R&D계획서·개발보고서·시험성적서·품질기록·회의록·교육자료·지재권 관리대장) 사전 정리

### 3. 기업부설연구소·연구개발전담부서
- **연구전담요원 수(부록 B 기준)**: 벤처 2 / 연구원·교원 창업기업 2 / 소기업 3(창업 3년 이내 소기업 2) / 중기업 5(소기업→중기업 전환 후 1년까지 3) / 중견 7 / 대기업 10 / 해외 소재 연구소 5(규모 무관) / **연구개발전담부서 1명 이상(규모 무관)** — 76장 본문 표와 다름(→ 16부 노트 6절 참조)
- **연구전담요원 자격**: 상시 전담 가능 / 관련 분야 학위·전공·자격·경력 / 4대보험 가입 / 계약직은 기간·실제 수행 가능성 / 주간 대학원 재학생은 원칙적으로 제한 가능 / 국가연구개발사업 참여 석·박사과정·야간대학원 등은 예외 가능 / 연구소장도 요건 충족 시 인원 포함 검토
- **연구공간**: 독립된 연구공간(타 부서와 명확 구분), 명패 부착, 책상·의자·컴퓨터·장비, 실제 연구 목적에 맞는 기자재, 고정벽체가 어려우면 이동벽체 방식 검토, 부소재지 연구소는 소재지별로 인적·물적 요건 충족
- **연구활동 자료**: 연구개발활동 개요서, 향후 1년 대표 연구과제, 과제별 목표·내용·기간·개발비, 연구 기자재 현황, 연구전담요원 현황, 조직도·인사발령, 공간 사진·배치도, 연구노트·회의록·시험자료·개발보고서
- **보완 포인트**: **설립보다 사후관리가 더 중요**. 전담요원 퇴사·겸직, 연구공간의 업무공간 전용이 사후관리 문제. 연구소 인정서만 있고 연구활동 기록이 없으면 세액공제·벤처확인·정책자금·R&D 신청 및 세무검토에서 불리

### 4. 메인비즈
- 경영혁신형 중소기업. 대상: 업력 3년 이상 중소기업, 서비스·유통·비제조·플랫폼·프랜차이즈·지식서비스·경영관리 우수 제조업
- **합격 기준(책 기준)**: 온라인 자가진단 **600점 이상** / 현장평가 **700점 이상** / 확인서 유효기간 시작일부터 3년, 만료 전 연장·재평가 / 평가기관 신보·기보·한국생산성본부(연장평가는 메인비즈협회 위탁 가능)
- **평가 구조(1,000점)**: 경영혁신인프라 350 / 경영혁신활동 400 / 경영혁신성과 250
  - 인프라: 비전·전략·리더십, 3년 이상 사업계획서, 수치화된 경영목표, 목표 대비 실적 점검, 조직도·직무분장·위임전결규정, 운영자금·자금관리, 지재권·인증·수상 이력
  - 활동: 제품·서비스 개선, 프로세스 개선·원가절감·납기단축, ERP·CRM·그룹웨어 등 IT 도입, 업무 자동화·디지털 전환, 고객관리·클레임·사후관리 문서화, 마케팅·신규고객 확보, 임직원 교육훈련, 제안제도·회의체·개선활동·코칭
  - 성과: 3년 매출·영업이익·당기순이익, 고용 증가·상시근로자, 고객만족도·피드백, 신규고객·유지율, 품질개선·불량률·납기 준수, 수상·인증·공공조달·수출·투자유치
- **보완 포인트**: "경영을 잘하고 있다" 같은 추상 설명으론 부족, **문서화된 경영시스템 + 정량 성과**. 서비스·유통업은 기술자료가 부족해도 고객관리·프로세스 개선·IT 도입·매출·고용·고객만족도가 정리돼 있으면 준비 가능

### 5. 인증별 실무 판단 순서
| 기업 유형 | 검토 순서 |
|---|---|
| 기술개발 중심 | 연구소 또는 전담부서 설립 → 벤처(연구개발유형·혁신성장유형) → 이노비즈 → 정책자금·R&D·세액공제 연계 |
| 경영관리 중심 | 경영전략·사업계획서 정비 → 업무 프로세스·성과관리 자료 정비 → 메인비즈 → 정책자금·보증·금융우대·공공조달 가점 연계 |
| 조기 창업기업 | 연구개발전담부서·연구소 설립 가능성 → 벤처 혁신성장유형·예비벤처 → 사업계획서·기술개발계획·시장진입전략 보완 → 정부지원·창업지원·R&D 기획과제 연계 |
- 4개 제도(벤처·이노비즈·메인비즈·연구소)는 독립 제도이지만 **연결해서 검토**. 기준·제출서류는 법령·고시·운영규정에 따라 변동 → 신청 전 벤처확인시스템·이노비즈넷·메인비즈 인증시스템·기업부설연구소 신고관리시스템의 최신 안내 확인
