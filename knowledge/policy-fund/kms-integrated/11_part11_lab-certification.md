# 11부: 기업부설연구소·인증 실전 가이드 (49~54장)

## 개요 (책 요약)
- 연구인력개발비 세액공제: 당기분 25% / 증가분 50% / 신성장·원천 30~40% 중 매년 유리한 방식 선택. **초과분 5년 이월**(세무조정계산서에 누락 시 소멸 → 대표가 직접 확인)
- 연구소 부동산: 취득세 60%, 재산세 50%, 연구용 수입물품 관세 80%, 연구활동비 월 20만원 비과세
- 반려 사유 1위: 사진에서 **독립 출입문** 미확인
- 창업 3년 이내 소기업은 **대표자를 연구전담요원으로 편입** 가능(학사 이상 또는 기사 이상, 다른 연구원 1명 이상) → 직원 1명으로도 설립 가능한 경우
- **변경사항 14일 이내 미신고, 연구개발활동조사표 4월 말 미제출 = 인정 취소 사유**, 취소 시 기 수령 세액공제 **소급 추징**(과거 연도 전체 재계산)
- 인증 7종 최적 순서: 연구소(설립 즉시) → **벤처(설립 3년 이내 필수, 넘으면 법인세 50% 감면 소멸)** → ISO 9001(이노비즈 전제) → 직무발명보상우수기업(특허 연차료 50%) → 메인비즈 → 이노비즈
- 이노비즈: 기보 보증 30억→50억, 금리 최대 1.65%p 우대, 세무조사 유예, 코스닥 요건 완화

## 49장. 연구소 세액공제

| 방식 | 중소기업 공제율 | 계산 | 유리한 경우 |
|---|---|---|---|
| 당기분 | 25% | 당해 R&D비 × 25% | 매년 비슷 |
| 증가분 | 50% | (당해 − 직전) × 50% | 전년 대비 급증 |
| 신성장·원천 | 30~40% | 해당 R&D비 × 30~40% | AI·바이오·그린 등 |

| 시나리오(책) | 연구원 | 평균연봉 | R&D비 | 공제 |
|---|---|---|---|---|
| 소기업 기본 | 2명 | 3,500만 | 7,000만 | 1,750만 |
| 소기업 성장 | 5명 | 4,000만 | 2억 | 5,000만 |
| 중기업 표준 | 10명 | 4,500만 | 4.5억 | 1.125억 |

- 부동산 감면: 중소 취득세 60%(대기업 35%), 재산세 50%. **과밀억제권역 내 연구소는 지방세 감면 제외**
- 세무조사 대비 증빙: 실시간 연구노트, 개발품의서(목표·방법·기간), 결과물(시제품·시험성적서·출원증), **구분경리**, 연구인력 4대보험, 인사발령서
- 대표 직접 체크: 세무조정계산서에 세액공제 항목 기재 / 이월공제 반영 / 연구요원 인건비 별도 계정 / 부동산 감면 신청
- 핵심은 서류의 존재가 아니라 **서류의 연결**(프로젝트별 노트·인건비·재료비·결과물 한 세트)

### 연구전담요원 자격(중소기업)
- 자연계 학사 이상(관련 전공 또는 1년 이상 근무)
- 자연계 전문학사 + 경력(2년제 2년, 3년제 1년)
- 마이스터고·특성화고 + 관련 R&D 4년
- **국가기술자격 기사 이상**(학위 없이 가능, 현장에서 가장 많이 활용)
- 산업기사 + 관련 경력(중소기업 한정)
- 산업디자인·지식기반서비스 분야는 비자연계 학위 인정

### 공간
- 원칙: 사방 벽체 분리 + 독립 출입문
- 예외: 소기업·지식기반서비스 기업, **연구공간 30㎡ 이하는 파티션 허용**(기자재는 파티션 내부)
- 연구기자재는 연구공간 내 위치, **현판 사진 필수**

### 설립 신고 (KOITA 온라인, 선설립 후신고, 7~15일)
필수 서류: 사업자등록증 / 중소기업기준검토표(세무사·회계사 날인) / 조직도(20인 이하 전체 명단) / 연구소 도면(면적) / 사진(전용 출입구·현판·내부) / 연구원 이력서·졸업증명·자격증·경력증명 / 인사발령서 / 4대보험 가입자 명부 / 건축물대장 / 임대차계약서 / 연구소장 이력서 / 연구사업 개요서 / 기술사업계획서·인원증원계획(10인 미만) / 생산시설 설비현황
- 세 묶음: 기업 기본 / 인력 / 공간
- 반려 사유: 독립 출입문 미확인, 학위·경력 증빙 불완전, 중소기업기준검토표 누락·미날인, 도면과 사진 면적 불일치, 기자재가 공간 외부

## 51장. 연구소 사후관리

- 변경신고 **14일 이내**: 요원 퇴직·채용, 위치 이전·면적 변경, 명칭, 대표자, 기업 유형, 연구소장, 연구분야
- 불이행 결과: 기준 미달 1개월 내 미보완 → 취소 / 변경사유 1년 이내 미신고 → 취소 / 세액공제 소급 추징 / 세무조사 시 반드시 확인
- **연구개발활동조사표 매년 4월 말** 제출(미제출 시 취소)
- KOITA **사전 통보 없는 현지 확인** 적발 3대 유형: 연구원 영업·생산 겸직 / 연구공간 창고·회의실 전용 / 연구노트 미작성·형식적
- 일상 관리: 연구노트 매일, 출근부·업무일지, 공간 목적 외 사용 금지, 기자재 공간 내, 4대보험 유지, 변동 시 14일 내 신고

## 52장. 병역특례 (전문연구요원)
- 근거: 병역법 제36조, 36개월 복무, 자연계 석사 이상
- 기업 요건: **기업부설연구소(전담부서 불가) + 병역지정업체 지정 + 자연계 석사 이상 연구전담요원 2명 이상(중견 5명)**
- 효과(책): 석사 연구원 2명(각 4천만) → 세액공제 연 2천만, 3년 6천만 + 핵심 인력 3년 확보
- 절차(병무청 4단계): 신청(연 1~2회 공고) → 심사(현장방문) → 지정(배정까지 2~3개월) → 관리(연간 보고)
- 위반 시 현역 입대 + 지정 취소: 연구 외 겸직 / 연구소 외 파견 / 복무 중 무단 이직 / 연구실적 부실·허위 보고
- 신청 전 연구소 설립 후 **최소 6개월 실제 연구활동 이력** 필요, 지정까지 3~5개월

## 53장. 성장 단계별 인증 순서

| 인증(책) | 소요 | 핵심 요건 | 대표 혜택 |
|---|---|---|---|
| 기업부설연구소 | 15일 | 연구원 3명(소기업) + 독립공간 | 세액공제 25% + 지방세 감면 |
| 메인비즈 | 60일 | 3년 + 매출 + 700점 | 금리감면, R&D 가점, 수출 지원 |
| 벤처기업 | 60일 | 기보 보증 또는 R&D 5% 등 | 법인세 감면(3년 이내), 보증료 인하 |
| 직무발명보상우수기업 | 60일 | 규정 + 실제 보상 | 특허 연차료 50% + 가산점 |
| ISO 9001/14001 | 90일 | 경영시스템 구축·심사 | 이노비즈 전제, 수출 신뢰 |
| 이노비즈 | 90일 | 3년 + ISO + 특허 + 연구소 + 700점 | 보증 30→50억, 금리 1.65%p, 세무조사 유예 |
| 성과공유기업 | 60일 | 성과공유제 도입 | 가점 1점, 사업화 자금 가점 |
- 3개 이내 선택해 집중

### 벤처 혜택 (설립 3년 이내 인증 시)
법인세(소득세) 50% 감면 5년 / 법인 설립·부동산 취득 등록세·취득세 감면 / 재산세 50% / 코스닥 기술특례상장 / 특허 우선심사 / 기보 한도 우대 / 라디오 광고비 70% 감면 / 병역특례 가점

### 이노비즈 선정 기준
- **기술혁신시스템 평가 700점(1,000점 만점) 이상 + 개별기술수준 B등급 이상**
- 필수: 설립 만 3년 경과, ISO 9001 또는 14001, 지식재산권, 기업부설연구소
- 혜택: 15개 시중은행 협약, 기보 30→50억, 금리 최대 1.65%p, 취등록세 감면, **정기 세무조사 유예**, 코스닥 요건 완화, 병역지정 가점, 조달청 신인도 가점, 라디오 광고비 70%, 특허 우선심사

### 최적 취득 순서
1단계 연구소/전담부서(설립 즉시~3개월) → 2단계 벤처(1~2년, **3년 이내 필수**) → 3단계 ISO 9001(1~3년) → 직무발명우수(2~3년) → 메인비즈(3년+) → 이노비즈(3년+) → 성과공유·여성·청년기업(필요 시)
- 실패 방지 3원칙: 순서 / 타이밍(벤처 3년 이내, 이노비즈 3년 이후) / 사후관리
- **자금 신청 일정에서 역산**(이노비즈 4~6개월)

## 54장. IP 펀드와 기술금융
- **Death Valley**: 신용등급 BB 미만 + VC 투자 미확보 구간 → 기술등급 **T4 이상**이면 IP 기반 자금조달 기회
- IP 펀드(Sale & License Back): 특허를 펀드에 매도 → 전용실시권 유지 → 매년 실시료 → 만기 시 재매입. 차입 없이 현금 확보, 독점권 유지
- 사례(책): SW기업 특허 2건+SW 등록, 매출 13억, 30억 평가 → IP 담보 5억 / 매출 135억, 51억 평가 → 15억 / 안마의자 특허 12건, 매출 780억, 500억 평가 → IP 20억+유동화 200억 / 기능성화장품 특허 2건, 매출 47억 → 기보 5억에서 신보 전환+추가 5억
- **신보 IP 우대보증: SMART3 평가 B등급 이상 특허 건당 1억**, B 미만은 미실행 → 강한 청구항의 핵심 특허가 중요(수량보다 품질)
