# 8부: 실전 서류·사례·실행 시스템 (34~36장)

자금조달 실패는 전략 부재가 아니라 **실행 시스템 부재**에서 온다. 3가지 도구: 서류 패키지 / 합격·탈락 패턴 / 연간 캘린더

## 34장. 서류 패키지

- 기관별 요구서류의 **80%가 공통**. 보완 요청 1위는 "서류 부족"이 아니라 **"숫자가 맞지 않음"**(재무제표·부가세·신청서 불일치)
- 부가세 매출과 재무제표 매출이 다르면 **차이 사유 설명 메모를 사전에 준비**
- 기관 검토 4축: 정합성 / 신뢰성(체납·연체·대표 이슈) / 상환·성장성 / 실체성(실제 사업장·인력·거래)
- 심사 7단계: 사전준비 → 접수 → 서류검토 → 현장평가 → 심의·의결 → 약정 → 실행·사후관리

### 공통 패키지 (6묶음)
| 패키지 | 서류 | 갱신 | 주의 |
|---|---|---|---|
| 기본 | 사업자등록증, 법인등기부, 정관, 주주명부, 인감증명 | 연 1회·변경 시 | 최신본 |
| 재무 | 최근 3개년 재무제표, 부가세 신고서, 원천징수 | 결산 후 즉시 | 세무대리인 날인 |
| 납세 | 국세·지방세 완납증명, 4대보험 납부확인 | 신청 직전 | 유효 30일 |
| 인력 | 4대보험 가입자 명부, 급여대장, 조직도 | 분기별 | 신고=실인원 |
| 사업 | 거래처 계약서·발주서·세금계산서 | 거래 시 | 상위 3개 거래처 필수 |
| 성장 | 인증서, 특허증, 연구소 인정서, 수상 | 취득 시 | 유효기간 관리 |

### 기관별 추가 서류
- 기보: 기술보증 여신거래 신청서, 기술 설명자료(사양서·경쟁기술 비교표), 특허증·출원접수증, 책임경영 체크리스트, TCB 의뢰서
- 신보: 신용보증 신청서, 여신거래기본약정서, 주요 거래처 현황·매출채권 명세, 담보 서류
- 중진공: 융자신청서, 사업계획서(중진공 양식), 창업기업 확인서, 기술개발 실적(개발기술사업화)

### 디지털 폴더 구조 (권장)
01_법인기본 / 02_재무세무 / 03_납세증빙 / 04_인력관리 / 05_사업증빙 / 06_인증특허 / 07_신청이력

## 35장. 합격·탈락 사례

| 사례 | 기업 | 핵심 | 결과 |
|---|---|---|---|
| 합격 A | 금속가공(C2251), 안산, 업력 5년, 매출 15억, 12명, 대표 신용 3등급, 부채비율 148%, BB, 등록특허 2건 | 특허를 TCB 핵심기술로 연결, **매출 안정성 패키지**(발주서+6개월 세금계산서), 설비 후 생산성 40%↑ 공정 데이터 | 기보 3억(보증료 0.8%, T4) → 2개월 후 중진공 신성장 시설 5억 = **8억**. **동시 신청 대신 순차**(부채비율 급등 방지) |
| 합격 B | SW개발(J5822), 마포, 업력 2년, 매출 3억, 4명, 상위 2개사 78% | 예창패·초창패 이력을 TCB 참고자료로, 연구전담부서 설립(1명, 3주), 신규 거래처 3곳 협의 이메일 | 초창패 5천(무상) → 기보 1.5억 → 중진공 창업 1억 = 2.5억. **무상 지원사업 → 기보 → 중진공 = IT 초기기업 표준 경로** |
| 탈락 A | 교육서비스, 대구, 업력 3년, 매출 8억 | 부가세 매출 7.2억 vs 재무제표 8억, 대표 "세무사가 처리" → 48시간 내 보완 실패 | 원인은 현금매출 8천만. 3개월 후 차이 사유·현금거래 내역서 **선제 제출**로 승인 |
| 탈락 B | 금속가공, 화성, 업력 6년, 매출 18억 | **지방소득세 34만원 체납**(자동이체 잔액 부족) → 완납증명 불가 | 3억 전체 탈락, 6개월 지연 + 고금리 이자 손실 약 1,080만원 → **분기 1회 홈택스·위택스 조회 습관화** |
| 합격 C | 한식당 2곳, 창원, 업력 6년, 매출 4.5억 | "정책자금은 제조업만" 오해. 대형 프랜차이즈 입점으로 매출 28% 감소 → 부가세 반기 비교로 수치화 | 소진공 긴급경영안정(경영애로) 7천만(2.4%) → 지역신보 5천만 추가 |
| 재도전 합격 | 플라스틱 제조, 평택, 업력 8년, 매출 22억 | 1차: 기보 TCB T6 보증 불가(가지급금 1.8억, 부채비율 238%, 이자보상 0.9배) → 6개월 준비: 가지급금 1.2억 대여금 전환(인정이자 4.6%) + 0.6억 급여조정 상환, 설비 매각으로 단기차입 1억 상환(부채비율 189%), 고원가 라인 2개 정리, 이노비즈 취득(4개월) | TCB T4, 기보 3억(0.7%) + 중진공 신성장 시설 = 7억 |

- 탈락 당시 vs 재신청 개선: 매출 차이 즉답 → 사전 소명자료 / 세무사 의존 → **주요 수치 5개 암기·리허설** / 신청 직전 교차 확인 없음 → **부가세·재무제표·사업계획서 3중 교차 확인**
- 가지급금·부채비율·TCB 등급은 **6개월 내 의미 있게 개선 가능** → 탈락은 다음 신청의 가이드북
