# 2부: 창업 준비기 (창업 0~6개월, 8~10장)

창업 후 6개월의 세 가지 선택(사업자 유형, 업종코드, 신용 설계)이 이후 수년간의 자금 접근성을 결정한다.

## 8장. 사업자 유형과 법인 설립

| 항목 | 개인사업자 | 법인 |
|---|---|---|
| 세율 | 종합소득세 6~45% 누진 | 법인세 4구간(책 기준, 2026.1.1. 이후 개시 사업연도): 2억 이하 10%, 2억~200억 20%, 200억~3,000억 22%, 3,000억 초과 25% → **세무사 확인 필수** |
| 자금조달 | 기보·신보·중진공 접근 제한적 | 대부분 정책자금 접근 가능 |
| 책임 | 무한책임 | 유한책임 |
| 4대보험 | 사업주 별도 | 대표이사 포함 의무 가입 |
| 인증 | 일부만 가능 | 대부분 가능 |
| R&D | 제한적 | 과제 참여·세액공제 완전 활용 |
| 신뢰도 | 낮음(B2B 불리) | 높음 |

### 업종코드(한국표준산업분류, KSIC) 확인 사항
- 주력 사업과 코드 일치
- 제조업 vs 서비스업(R&D 세액공제율 차이)
- 벤처 인증 업종 제한 여부
- **중진공·소진공 지원 제외 업종 해당 여부**
- 사업 확장 시 추가 코드 필요 여부
- 예: 소프트웨어 개발(62)은 지식서비스업 우대, 같은 사업을 도소매로 등록하면 혜택 없음

### 창업기업 인정 기준 (중소기업창업 지원법 시행령, 2024.7.10. 개정, 대통령령 제34657호)
**창업 제외 6가지 (하나라도 해당하면 창업 아님)**
1. 타인으로부터 사업을 상속·증여받아 동종 사업 개시 (이종 전환은 창업 인정)
2. 기존 개인사업 유지하면서 동종 법인 신설 (지분 30% 이상 또는 최대주주 → 창업 아님 / 30% 미만이고 최대주주 아니면 인정)
3. 폐업 후 동종 사업 재개: 폐업 3년 이내(부도·파산 2년 이내) → 창업 아님
4. 법인이 발행주식 50% 초과(임원 소유 합산) 자회사를 설립
5. **과점주주 함정(2024.7.10. 개정)**: 기존 법인의 과점주주가 새 법인의 과점주주가 되어 사업 개시 → 창업 아님. 국세기본법 제39조 특수관계인 합산 → **부모 회사 지분 1%만 있어도 자녀 신설법인이 창업 불인정될 수 있음**(스핀오프·분사 시 사전 확인 필수)
6. 조직변경(주식회사↔유한회사 등)으로 동종 사업 계속

- 동종 판단: 표준산업분류(10차) **세세분류 5자리 모두 일치**하면 동종
- 업력 기산일: 법인 = 법인설립등기일 / 개인 = 사업자등록증상 개업일
- **개인 → 법인 전환 시 업력은 개인 개업일부터 기산**(개인 5년 운영 후 법인 설립 = 업력 5년)
- 창업 지위 승계: 창업기업인 개인이 본인이 대표인 신설 법인에 사업 **포괄이전** 시 승계(일부 이전·대표자 다르면 불인정)
- 경과조치: 2020.10.8. 이전 창업자는 종전 규정으로 7년간 창업자 인정

### 법인 설립 후 첫 30일 체크리스트
- [ ] 사업자등록(설립 후 20일 이내)
- [ ] 사업용 계좌 개설(대표 개인계좌와 완전 분리)
- [ ] 법인카드 발급·사용 규정
- [ ] 4대보험 취득·성립 신고(책 기준 14일 이내, 기한은 공단 안내로 확인)
- [ ] 업종코드와 실제 사업 일치 검증
- [ ] 주주명부·이사회 의사록 원본 보관
- [ ] 세무대리인 선임·기장 계약
- [ ] 세금계산서 발급 체계
- [ ] 창업기업 확인서 신청(창업진흥원)
- [ ] 첫 신용거래(법인카드 정시 결제)

## 9장. 창업 직후 정부지원사업

| 구분 | 예비창업패키지 | 초기창업패키지 | 창업도약패키지 |
|---|---|---|---|
| 대상 | 예비창업자(사업자 미등록) | 창업 3년 이내 | 창업 3~7년 |
| 지원 규모 | 최대 1억 | 최대 1억 | 최대 3억 |
| 지원 | 사업화자금·멘토링 | 사업화·판로·기술 | 도약·글로벌 |
| 평가 핵심 | 혁신성·아이디어 | 시장성·사업화 | 성장성·실적 |

- 사업계획서는 **처음 2페이지(문제 정의 + 해결 방안)에서 점수 절반이 결정**. 이어서 고객 검증, 팀 역량, 사업화 계획
- 지자체 지원사업(경기 창업오디션, 서울 SBA 등) 놓치지 말 것. 경쟁률 낮은 경우 많음
- 초기 자금은 **적게, 빠르게, 전략적으로**: 창진원·지역 창업지원·소진공 → 성과 증빙 → 기보·신보

## 10장. 첫 신용등급 설계

- 법인 신용은 0에서 시작 → 초기엔 대표자 개인 신용 의존. **창업 6~12개월이 골든타임**
- 원칙 1: 법인카드·세금·4대보험 **단 한 번도 연체 금지**(1회 연체가 6개월~1년 기록)
- 원칙 2: 주거래 은행 하나로 집중
- 부정 이력 해소에 최소 1~2년 소요

### 여신평가 필수서류
| 구분 | 항목 | 주기 | 주의 |
|---|---|---|---|
| 법인 기본 | 사업자등록증, 법인등기부, 정관, 주주명부 | 연 1회 갱신 | 최신본 확인 |
| 재무 | 재무제표, 부가세 신고서, 원천징수 | 분기별 | 결산 후 즉시 정리 |
| 납세 증빙 | 국세·지방세 완납증명서 | 신청 직전 발급 | 유효기간 30일 |
| 인력 | 4대보험 가입자 명부, 급여대장 | 수시 | 신고 인원과 실제 인원 일치 |
| 계약 | 주요 거래처 계약서·발주서·세금계산서 | 거래 시마다 | 매출 증빙 연결 |

### 신용등급별 자금·금리·다음 목표 (책 기준 예시)
| 등급 | 자금 | 금리 | 다음 목표 |
|---|---|---|---|
| B 이하 | 소진공 희망리턴패키지, 정책자금 제한 | 연 5% 이상 | 결격 해소 후 재시작 |
| B+~BB- | 신재 지역보증, 소진공 직접대출 | 연 3~5% | BB- 진입으로 기보 접근 |
| BB- | 기보·신보 보증연계 | 연 2.5~4% | BB로 한도 확대 |
| BB | 중진공 직접대출, 기보·신보 풀 활용 | 연 2~3.5% | BB+로 온렌딩 |
| BB+ | 산은 온렌딩, 한은 금중대 | 연 1.5~2.5% | A등급 |
| A 이상 | 전 상품, 최저금리 협상 | 연 1~2% | 투자·상장 연계 |
