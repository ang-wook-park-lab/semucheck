# 4부: 정부자금 — 중진공·소진공 직접대출 (16~20장)

## 16장. 정부자금은 신용등급보다 기업평가

| 항목 | 민간자금(기보·신보) | 정부자금(중진공·소진공) |
|---|---|---|
| 출발점 | 상환 능력 | 정책 목적 부합성 |
| 신용등급 | 핵심 요건(BB- 이상) | 참고 요소 |
| 사업계획서 | 보조 | **핵심 심사 자료** |
| 대표 면담 | 일부 | 거의 필수 |
| 현장 방문 | 선택적 | 자주 |
| 성과 요구 | 상환만 | 고용·매출·수출 성과 보고 |

- 정책 효과 기준: 고용 창출, 매출 성장, 수출 증가, 기술 사업화, 지역 균형 → **수치로 제시**
- 정성평가 고득점: 대표가 "시장 문제 → 해결책 → 현재 성과 → 향후 계획" 순서로 설명, 서류와 구두 설명 일관, 정책 효과를 숫자로
- "우리 회사가 힘들다" 호소 ✗ → **어려움 인정 + 구체적 해결 계획** ○ (힘든 기업보다 준비된 기업)

## 17장. 중진공 3대 직접대출

| 자금 | 대상 | 심사 핵심 |
|---|---|---|
| 창업기반지원자금 | 업력 7년 이내 | 아이템 시장성, 대표자 역량, 정부지원사업 이력 가점 |
| 신성장기반자금 | 성장 기업 | 정책 키워드(스마트제조·소부장·탄소중립·디지털전환) 연결 |
| 개발기술사업화자금 | 특허·시제품·초기 납품 실적 | 기술의 사업화 가능성 |

### 창업기반지원자금 (2026 공고 기준, 책)
| 항목 | 운전자금 | 시설자금 |
|---|---|---|
| 한도 | 연간 5억 이내 | 60억 |
| 기간 | 5년(거치 2년) | 10년(거치 3년) |
| 금리 | 정책자금 기준금리 + 가산(변동) | 동일 |
| 심사 특이점 | 현금흐름·영업력 | 설비 투자 계획 현실성 |
- **청년전용창업자금**: 대표 만 39세 이하 + 업력 3년 미만, 최대 1억(제조·중점분야 2억) — 일반 운전자금 5억과 혼동 금지

### 통과하는 사업계획서 3요소
1. 자금 용도와 금액 근거: "설비 3억 + 원자재 5천만 + 인력 채용 5천만"
2. 현실적 성과 예측: "6개월 후 매출 20%↑, 12개월 후 고용 3명↑"
3. 리스크 분석과 대안

## 18~19장. 소진공 소상공인 정책자금

- 대상: 소상공인(상시 5인 미만, 숙박·음식 등 일부 10인 미만) 또는 소공인(제조업 10인 미만). **일반 중소기업은 대상 아님 → 첫 단계에서 확인**
- 직접대출(소진공 심사·실행, 지역센터 방문, 경쟁률 높음) vs 대리대출(소진공 확인서 → 은행 심사·실행)
- 자금 선택 논리 중요: 경영난인데 성장기반자금 신청 / 성장 목표인데 경영안정자금 신청 → 앞뒤가 안 맞아 탈락
- 중진공과 별개 기관 → **병행 활용 가능**
- 실무: 소상공인 확인서 사전 발급, 제외 업종 확인, **1~2월 신청 유리(예산 조기 소진)**, 사업장 사진·계약서, 연대보증 여부, 중복 지원 제한

### 공통사항
- 한도: 소진공 대출잔액 + 신규 합산 **운전자금 기업당 5억, 시설 포함 10억**. 긴급경영안정은 별도
- 금리: 정책자금 기준금리(분기 변동) + 가산금리, 일부 고정
- 접수: 온라인(소상공인정책자금 사이트) 또는 지역센터(전국 78곳). 대리대출 1월 5일, 직접대출 1월 12일 접수 개시(2026)

### 우대금리 (최대 0.8%p, 동일 유형 내 중복 불가, 고정금리 상품 제외)
| 유형 | 대상 | 우대 |
|---|---|---|
| 정책 우대 | 소진공·은행권 컨설팅 수료, 제로페이·디지털 온누리 가맹점 | 0.1%p |
| 정책 배려 | 여성기업, 장애인기업, 일회용품 규제 우수 | 0.1%p |
| 사회안전망 | 자영업자 고용보험, 전통시장 화재공제, 풍수해보험, **노란우산공제** | 0.1%p |
| 성실상환 | 소진공 직접대출 최근 3년 내 10일 이상 연체 없이 분할상환 중·완제 | 0.3%p |
| 지역격차 해소 | 비수도권(수도권 인구감소지역 포함) | 0.2%p |

### 융자 제한 8가지 (상담 첫 단계 체크)
1. 세금 체납 (압류·매각 유예 시 직접대출에 한해 가능)
2. 신용도판단정보·공공정보 등록(연체·부도·회생)
3. 허위·부정 신청, 용도 외 사용
4. 임직원 자금횡령 등 사회적 물의
5. 휴·폐업 중 (재해 원인 휴업은 가동 간주)
6. 융자제외 업종(사행·도박·유흥·금융·보험·법무·세무·부동산 일부 등)
7. **최근 5년 이내 정책자금 3회 이상 지원** (특별경영안정 미포함, 시설자금·직접대출 성실상환자는 1회 추가)
8. 동일 연도 동일 자금 부결·승인 후 6개월 미경과(직접대출, 승인 후 전액 포기 포함)

### 자금별 실무 포인트
- **신용취약자금**: 신청 전 소상공인 지식배움터 신용관리 교육 필수. 1년 후 신용점수 70점↑ 또는 840점 이상 회복 시 0.5%p 금리인하
- **대환대출**: 7% 이상 고금리 → 4.5% 고정 10년. 고금리 보유 고객은 최우선 검토
- **재도전특별**: 유형별 한도·금리 최대 3배 차이 → 유형 먼저 판별
- **혁신성장촉진 졸업후보 특례**: 소기업 성장 시 금리 0.4%p 추가 인하 + 중진공 연계
- **긴급경영안정**: 매출 15% 감소 확인(연·반기·분기·월 선택). 고용위기지역·산업위기대응특별지역·상권활성화구역 등 **7가지 예외**는 감소 확인 불필요
- 우대금리 조합 예: 노란우산(0.1) + 비수도권(0.2) + 성실상환(0.3) + 여성기업(0.1) = 0.7%p

## 20장. 정부자금 성공 공식

- 성공 5단계: 현황 진단 → 신용·재무 정비 → 가점 요소 확보 → 맞춤 자금 설계 → 심사 대응·실행 관리

### 업력별 자금 연계 로드맵 (책 사례)
| 업력·조건 | 로드맵 |
|---|---|
| 창업 2년차, 기계제조 + 연구소 + 벤처 + 특허 | 한은 C1 운전자금(은행 온렌딩) → 중진공 창업기반지원 + TIPS형 창업성장기술개발(디딤돌) 병행, 벤처로 기보 보증료 감면 + 신보 IP 보증으로 특허 자본화 |
| 창업 8년차, 기계제조 + 연구소 + 이노비즈 + 특허 | 지자체 육성자금(운전) → 중진공 개발기술사업화(특허 연계) + 고성장촉진 → 중기 기술혁신개발(시장대응형), 이노비즈 가점 + 기보 이노비즈 협약보증 |
| 창업 9년차, 위 조건 + 매출 성장 | 신보 유동화보증(매출채권) → 중진공 미래기술육성(혁신성장분야) → 구매조건부 신제품개발 → **3단계 병행으로 10~20억 레버리지** |
- 공통점: 민간(기보·신보) 기반 + 정부(중진공) 직접대출 + R&D 출연금(무이자) **3층 구조**

### 합격 사례
- 제조 A사(업력 4년, 매출 12억): 기보 2억 → 중진공 창업기반 3억. 특허 3건 TCB 활용 + "설비 도입 후 월 생산량 35% 증가"
- IT서비스 B사(업력 2년, 매출 5억): 예창패 → 초창패 5천만 → 지원사업 이력으로 기보 1.5억

### 탈락 사유 비율 (책)
서류 불일치 28% / 사업 설명 불명확 22% / 결격 요건 18% / 과도한 차입 15% / 자금 사용 계획 불명확 12% / 기타 5%
