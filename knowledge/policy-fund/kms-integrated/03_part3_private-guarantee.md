# 3부: 민간자금 — 기보·신보·신용보증재단 (11~15장)

세 기관 모두 "보증서 발급 → 시중은행 대출" 구조. 이름은 비슷해도 **심사 언어가 다름**.

| 항목 | 신보 | 신재(지역신보) | 기보 |
|---|---|---|---|
| 대상 | 일반 중소기업 | 소상공인·소기업·지역기업 | 기술 중심 중소기업 |
| 핵심 평가 | 신용·매출 안정성 | 지역 영업력·대표자 신용 | 기술사업성(TCB) |
| 최대 한도(책) | 30억(협약 등 예외) | 8억(지역별 상이) | 30억(우대 시 50억) |
| 보증료율(책) | 0.5~2% | 0.3~1.5% | 0.5~2% |
| 우선 검토 기업 | 매출·거래 이력 있는 일반 성장기업 | 소상공인·창업 초기 | 기술형 기업 |

## 11장. 기술보증기금

- TCB(기술사업성평가): 기술성(기술수준·독창성·특허), 시장성(규모·성장성·경쟁력), 사업성(경영진·재무·실현가능성), 경영역량 → 점수가 한도·보증료율 결정
- 절차: 상담 → TCB 의뢰서·여신거래신청서 제출 및 실사 → **책임경영 체크리스트** 제출(결격 확인)
- 기술 우위는 **수치로**: "경쟁 대비 성능 30%↑, 생산비 20%↓, 공정시간 50% 단축"
- 가점 3종: **벤처 인증, 이노비즈 인증, 기업부설연구소** → 한도 우대·보증료 인하·심사 간소화

| 보증 유형(책) | 대상 | 최대 한도 |
|---|---|---|
| 일반기술보증 | 기술력 있는 중소기업 | 30억 |
| 벤처기업 우대 | 벤처 인증 | 50억 |
| 이노비즈 연계 | 이노비즈 인증 | 40억 |
| 연구소 보유 우대 | 기업부설연구소 | 30억 |
| IP 기반 | 특허 등 IP 보유 | 20억 |

### 기보 특수목적 보증 (일반 은행 창구에서 안내 안 해줌 → 컨설턴트가 연결)
| 상품 | 대상 | 포인트 |
|---|---|---|
| R&D 보증 | R&D 과제 수행(개발성공 판정·기술이전, 3년 내) | 과제 종료 후 사업화 자금 연계 |
| 특허(IP) 보증 | 특허권 보유(대표 개인·법인) 또는 전용실시권자 | 신용 한도 외 IP 가치로 추가 한도 |
| 녹색기술보증 | 녹색기술 사업화, 기술평가 B등급 이상 | ESG·그린 연계 |
| 4차산업혁명 지원 | AI·IoT·빅데이터 등 영위 | 제조업 스마트화 |
| 스마트공장 지원 | 스마트공장 보급사업 참여·공급기업 | 바우처 연계 |
| 재기지원보증 | 채무조정·회생 진행 기업주 | 재창업·재기 고객 |

### 대표 설명 논리 (기보 면담 6단계)
1. 해결하는 문제와 시장 규모 → 2. 기술의 해결 방식(기존과 차이) → 3. 검증(특허·시험성적서·납품실적) → 4. 사업화 가능성(확보·협의 고객, 매출 근거) → 5. 자금 용도와 매출 변화 → 6. 리스크와 대응

## 12장. 신용보증기금·신용보증재단

- 보증 실행 흐름: 상담 → 신청·서류 → 신용평가·현장조사·대표 면담 → 보증 결정(한도·기간·보증료) → 보증서 발급 → 은행 대출 신청 → 은행 심사 후 실행
- 소상공인(상시 5인 미만, 일부 업종 10인 미만)은 신재가 주 통로. 일반 중소기업은 신보. **매출 10억 이상 + 거래은행 있으면 협약보증**으로 간소화

### 보증기관이 좋아하는 구조 (진단 문항화 가능)
- 최근 3년 매출 증가·유지
- **상위 거래처 집중도 70% 미만**, 신규 거래처 확보
- 세금계산서 정기 발행
- 통장 입금의 규칙성
- 대표자 주거래 은행 장기 거래
- 부정기·급변 매출 없음

### 신보 상품 체계 (책 기준)
- 창업 4단계: 예비창업보증(창업 전 6개월, 10억) / 신생기업(3년 이내, 10~20억) / 창업초기(3~5년, 30억) / 창업성장(5~7년, 30억)
- 수출 4단계: 수출희망 특례(3억 운전) / 수출진입(연 수출 100만$ 미만, 30억) / 수출확장(100~500만$, 30억) / 수출주력(500만$ 이상, 30~70억)
- 가젤형 고용창출보증: 고용·매출 3년 연속 20% 이상 성장. 예비가젤(업력 2~5년, 2년 연속) 30억, 가젤(3~5년, 3년 연속) 30억, 선정 유효 3년
- IP 보증 4종: 개발 5억 / 이전 5억 / 사업화 10억 / 가치평가 10억 → **특허는 가점이 아니라 별도 한도의 근거**

## 13장. 신용보증재단 보증대출 (소상공인·소기업)

- 본질: 재단은 대출기관이 아니라 **보증기관** → 재단 승인 후에도 은행에서 감액·거절 가능. 비용 = 은행 이자 + 보증료
- 절차(비대면): ①은행 앱 등으로 보증신청·사전검증 ②대표자·사업장·임대차 정보 입력 ③보증심사(현장조사·추가서류) ④보증약정·보증료 납부 → 은행 실행
- 준비 서류: 신분증, 사업자등록 관련, 부가세 과세표준증명, 임대차계약서 / 추가 요청 가능: 4대보험 가입자 명부, 금융거래확인서

### 심사 5대 축
1. **기존 채무 구조**: 대출기관 3곳 초과, 카드론·캐피탈 과다 → 과다채무. **현금서비스는 소액이라도 감점**
2. **업력**: 3개월 미만 사실상 불가, 2년 이상 가점, 3년 이상 안정
3. **사업장 안정성**: 임차보증금 1천만원 이상 가점, 현 거주지 1년 이상, 본인·배우자 부동산
4. **체납·연체**: 월세·급여·국세·지방세·금융 연체 = 핵심 부결 사유
5. **대표자 실질 경영**: 실사 때 부재·설명 불가 = 심각한 리스크
- 신용점수(NICE): 710~750점 이상 권장, 700점대 초중반 이상 유리, **680점 이하 매우 보수적**

### 한도·금리·총비용
- 비대면 보증 최대 7천만원, 보증료 최대 2% 이내. 현장에선 2천~5천만원, 1억 내외, 특례 2억 이상도
- 은행별 금리 3.58~5.73%(2%p 이상 차이). 1금융 4~5% + 보증료 약 1%. 지자체 협약 특례 + 이차보전 시 실부담 2~3%
- 예: 3천만원, 5년(1년 거치 4년 균등), 은행 4.5% + 보증료 1% = 실질 약 5.5%
- **신청액은 필요액의 1.3~1.5배**(감액 대비) + 용도별 근거 제시

### 유리 vs 불리 사업자
| 항목 | 유리 | 불리 |
|---|---|---|
| 신용점수 | 700점대 초중반 이상 | 680점 이하, 최근 조회 다수 |
| 고금리 대출 | 현금서비스·카드론 없음 | 현금서비스·카드론·캐피탈 의존 |
| 대출기관 수 | 3곳 이내 | 3곳 초과, 매출 대비 과다 |
| 업력 | 1년 이상(2~3년 가점) | 3개월 미만 |
| 사업장 | 보증금 1천만원 이상, 거주 1년 이상 | 잦은 이사 |
| 세금·임금 | 완납, 급여 정상 | 체납, 월세 연체, 임금 미지급 |
| 매출 | 꾸준, 카드매출 증빙 | 급감, 현금매출 위주 |
| 대표자 | 실질 경영 | 명의 대표 |
| 업종 | 일반 업종 | 유흥·도박 등 제한업종 |

### 신청 전 9대 점검
1. 신용점수·최근 3개월 금융거래(다건 조회 이력)
2. 현금서비스·카드론·고금리 대출 정리
3. 국세·지방세·월세·급여 체납 여부(완납증명 가능)
4. 사업자등록증·부가세 과세표준증명·임대차계약서(잔여기간)·신분증
5. 최근 3~6개월 매출자료(카드·세금계산서·입금)와 자금 사용계획서
6. 대표자 1분 사업소개 스크립트
7. 은행 2~3곳 금리·보증료 총비용 비교
8. 특례보증·지자체 이차보전·비대면 상품 조회
9. 현장실사 대비(대표 상주, 재고·직원·간판 등 운영 흔적)

### 전문가 7전략
기관 선택 / 총비용 계산 / 심사자 선호 자료 준비 / 상담 예행연습(1분 소개, 자금용도표) / 타이밍(업력 2·3년, 세금 완납 직후, 좋은 분기 이후) / 은행 비교 / 비대면도 준비 수준 동일

## 14장. 민간자금 사전점검

### 신용평가 의뢰 전 체크 (준비만으로 1~2단계 상승 가능)
- [ ] 국세·지방세 완납증명 / 4대보험 납부확인 발급 가능
- [ ] 가지급금 최소화(가능하면 0)
- [ ] 단기차입금 비중(유동비율 영향)
- [ ] 결산 이익 수준
- [ ] 대표자 개인 신용 이상 없음
- [ ] 법인·대표 소송·가압류 없음
- [ ] 타 금융기관 연체 없음
- 담보 제공 전: 기존 근저당, 임대차 현황, 공시지가·실거래가 차이, 토지이용계획 제한

### 기본 서류 패키지
| 구분 | 항목 | 주의 |
|---|---|---|
| 법인 기본 | 사업자등록증, 등기부등본, 정관 | 3개월 이내 발급 |
| 재무 | 최근 2개년 재무제표, 부가세 신고서 | 세무대리인 날인 |
| 납세 | 국세·지방세 완납증명 | 30일 이내 |
| 인력 | 4대보험 완납확인, 근로자 명부 | 신고=실인원 |
| 사업 증빙 | 상위 3개 거래처 계약서·발주서·세금계산서 | 필수 |
| 대표자 | 신분증, 인감증명 | 법인 인감 |

### 보증 거절 10대 원인
세금 체납 / 4대보험 미납 / 자본잠식 / 대표자 신용불량 / 소송·가압류 / 서류 불일치 / 가지급금 과다 / 과도한 차입 / 사업장 부재(등록지와 다름) / 대표 설명 능력 부족

## 15장. 민간자금 실전 전략

- 경로: 창업 초기 신재 → 기술형 기보 우선 → 일반 성장 신보 강화 → 재무 안정 시 은행 직접대출 확대
- **한도 높이는 설명**: "운영자금 필요" ✗ → "월 매출 5천만원, A사 결제주기 60일 → 매월 부족 발생 → 운전자금 3억" ○
- 대표·회사 리스크 분리: 이사회 의사록, 자금 승인 체계, 법인카드 기준, 지출 결재 프로세스 문서
- 은행 대응: 보증 신청 전 주거래 은행 사전 상담, 한 곳 집중
- 수혜 후 용도대로 사용 + 매출·고용 성과 기록 → 다음 자금의 실적
