# 6부: 인증·연구소·특허 (25~29장)

**핵심: 인증·연구소·특허는 목적이 아니라 자금조달 레버리지. 자금 신청 6개월 전부터 순서대로 설계**

- 벤처 인증 → 기보 보증료 인하, 산은 C2 진입 완화
- 기업부설연구소 → 연구인력 인건비 25% 세액공제, 중진공 개발기술사업화 자격
- 등록 특허 → 기보 TCB 가점, IP 담보·보증으로 별도 한도
- 직무발명보상: 보상금에 대해 법인 R&D 세액공제(25%, 책 기준) + 임직원 소득세 비과세(연 700만원 한도, 책 기준). **규정은 자금 신청 전에 제정·시행돼 있어야 함**

## 25장. 인증은 자금보다 먼저

| 인증 | 정책자금 | 보증 | 세제 | 수출·공공조달 |
|---|---|---|---|---|
| 벤처 | 중진공 우대 | 기보 보증료 인하 | 취득세·등록세 감면 | 공공조달 가점 |
| 이노비즈 | 중진공·기보 우대 | 기보 한도 우대 | 연구개발 가점 | 수출 지원 우대 |
| 메인비즈 | 중진공 우대 | 신보 가점 | 일부 세제 | 공공조달 가점 |
| 기업부설연구소 | R&D 자금 자격 | 기보 기술평가 가점 | R&D 세액공제 최대 | R&D 과제 신청 |
| ISO 9001/14001 | 일부 우대 | 품질 신뢰도 | 일부 | 수출 거래처 신뢰 |

- 소요 기간: 벤처 4~8주, 이노비즈 3~6개월, 연구소 1~3개월 → **자금 신청 6개월 전 착수**
- 업종별 취득 순서: **제조업 = 이노비즈 → 연구소 → ISO 9001 / IT·SW = 벤처 → 연구소 → 이노비즈 / 서비스업 = 벤처 → 메인비즈 → ISO**
- 인증만으로 자동 승인되는 것은 아님(재무·대표자 신뢰 함께)

## 26장. 벤처기업 확인

| 유형 | 요건(책) | 난이도 | 적합 기업 |
|---|---|---|---|
| 기술보증형 | 기보로부터 8천만원 이상 보증·대출 | 중 | 기보 거래 기업 |
| 연구개발형 | 연간 R&D비 5천만원 이상 + 매출 대비 5% 이상 | 중상 | 연구소 보유·R&D 투자 기업 |
| 벤처투자형 | VC 등으로부터 5천만원 이상 투자 | 상 | 투자 유치 스타트업 |

- 혜택: 취득세·등록면허세 감면, 법인세 50% 감면(일부 조건), 기보 우대·보증료 인하, 공공조달 우대, 코스닥 기술특례상장
- 벤처 + 연구소 + 특허 + R&D 4종 연결 → 기보 한도 최대화, R&D 세액공제 극대화, 중진공 개발기술사업화, 산은 C2

## 27장. 이노비즈·메인비즈·ISO

- 이노비즈(기술혁신형): 기술 수준·개발 체계·보호·사업화·경영시스템. **1,000점 만점 700점 이상**. 병역특례(전문연구요원) 신청 자격, 공공조달 기술 가점, 보증료 인하
- 메인비즈(경영혁신형): 전략경영·인적자원·프로세스·고객관계·성과관리. 서비스·유통업에 유리
- ISO 9001: 품질경영 국제 인증. **대기업 벤더 등록 필수 조건인 경우 많음** → 매출 확장 직결

## 28장. 기업부설연구소·연구개발전담부서

| 항목 | 기업부설연구소 | 연구개발전담부서 |
|---|---|---|
| 연구전담요원 | 벤처·연구원창업: 2명 / 소기업: 3명(창업 3년 이내 2명) / 중기업: 5명 / 중견: 7명 / 대기업: 10명 | 규모 무관 **1명 이상** |
| 자격 | 자연계 학사 이상 원칙(중소기업은 전문학사·마이스터고 등 + 경력 인정), 서비스·디자인 분야는 비자연계 인정 범위 확인 | 동일 |
| 공간 | 독립된 연구공간(고정벽·별도 출입문 원칙, 일정 요건 시 50㎡ 이하는 칸막이 구분 인정) + 연구기자재 | 동일 |
| 연구소장 | 기재, 전임이면 요건 충족 필요(박사급 필수 아님) | 해당 없음 |

- 신고: **선설립 후신고**, 한국산업기술진흥협회(KOITA) 온라인 시스템
- 인정서만으로 세액공제·자금 승인이 자동 보장되지 않음 → 실제 지출·공고 요건 별도 검토
- 사후관리가 핵심: 연구노트 미작성, 연구원 4대보험 누락, 연간 실적 미신고 → **인정 취소 + 세액공제 추징**

### 연구소 설립 5단계
1. 연구개발조직 설계(주업종·분야·과제명·조직명). 단순 영업·생산·품질관리를 R&D로 포장 금지
2. 연구전담요원 확인(학위·전공·자격·경력·고용관계·4대보험, 전담 원칙)
3. 연구공간·기자재 확보(상시 근무 가능한 전용 공간, 회의실·형식적 공간은 위험)
4. 구비서류: 신고서, 연구개발활동개요서, 조직도, 공간 도면·사진, 요원 증빙, 사업자등록증, 중소·벤처 확인
5. 온라인 신고·보완 대응 (법정 처리기간 10일 이내)

### 연구소 사후관리 (인정 취소·과태료 리스크)
| 항목 | 관리 |
|---|---|
| 연구전담요원 | 인원·자격·전담·고용·4대보험 계속 확인 |
| 연구공간 | 이전·면적·부소재지 변경은 변경신고 |
| 연구기록 | 연구노트·실험기록·회의록·시제품·테스트 자료 날짜별 |
| 회계 | 연구 인건비·재료비·위탁연구비를 일반비용과 구분 |
| 연구개발활동조사 | **매년 4월 말까지 조사표 제출 의무** |
| 변경신고 | 상호·대표·소재지·분야·요원·공간 변동 시 |

### 신청 전 최종 체크
- [ ] 연구소 vs 전담부서 결정(규모·인원 기준)
- [ ] 요원 학위·전공·자격·경력 증빙
- [ ] 요원이 실제 R&D 전담 가능한 조직 구조
- [ ] 공간이 다른 부서와 명확히 구분, 상시 근무 가능
- [ ] 활동개요서 과제가 실제 R&D와 연결
- [ ] 연간 조사·변경신고 담당자 지정

## 29장. 특허와 IP는 조달 수단

- 특허의 자금 기여 3경로: ①기보 TCB 가점(등록 > 출원, 다수 > 1건, 핵심기술 직접 보호) ②IP 담보·보증(기보·신보, 가치평가 기관: 한국특허전략개발원 등) ③R&D 과제 신청 가점
- 포트폴리오: 핵심 권리특허 + 방어특허 균형, 수출시장(미·유럽·중국) 등록
- 물적 담보 없는 IT·바이오·콘텐츠 기업에 특히 유용

### 직무발명보상제도 (발명진흥법 제15조) — 3중 절세
| 법인 측(책, 2026 중소기업 기준) | 내용 |
|---|---|
| 손금산입 | 보상금 전액 비용 처리 → 법인세 절감 |
| R&D 세액공제(당기분) | 지출액의 25% 법인세 직접 차감 |
| R&D 세액공제(증가분) | 전년 대비 증가액의 50% (매년 유리한 방식 선택) |
| 신성장·원천기술 | 30%~ |
- 임원에게 지급한 직무발명보상금도 연구인력개발비 세액공제 대상(국세청 유권해석 사전-2015-법령해석법인-0316)

| 발명자 비과세 한도 | |
|---|---|
| 2016년 이전 | 한도 없음 |
| 2017~2018 | 연 300만원 |
| 2019~2023 | 연 600만원 |
| **2024년 이후** | **연 700만원** (단, 법인의 지배주주 및 특수관계 종업원 지급분은 비과세 제외) |

| 보상금 종류 | 시기 | 과세 |
|---|---|---|
| 발명(제안)보상금 | 발명 신고 | 과세(기타소득) |
| 출원보상금 | 출원 | 과세 |
| 등록보상금 | 등록 | 비과세(연 700만원 한도) |
| 실시(처분)보상금 | 실시 수익 발생 | 비과세(연 700만원 한도) |
| 출원유보보상금 | 출원 포기·유보 | 과세 |
- 실시보상금 산식(슬라이드법): 직무발명 매출액 × 독점기여도 × 실시료율 × 발명자 보상율 (독점기여도·보상율은 직무발명심의위원회 결정). 매년 분할 지급 가능
- 비과세 한도는 발명자 1인 기준, 공동발명자는 지분 안분

### 직무발명보상우수기업 인증 (특허청, 약 60일)
- 인센티브: 특허 우선심사, 연차등록료 추가 감면, 정책자금·R&D 가점, SGI서울보증 우대
- 순서: **규정 제정 → 등록보상금 1회 이상 지급 → 신청**. 이노비즈 전제 요건이기도 하므로 연구소 설립 다음 순위
