# 16부: 컨설팅 실전·경영분석·기업일반관리 (74~76장 + 별첨)

> 책 320~338쪽. 15부까지의 제도 지식을 **현장에서 작동시키는 방법**을 다룬다. 스캔 PDF라 일부 표는 OCR 판독이며, 불확실한 곳은 `[확인 필요]`로 표시했다.

## 개요
- **컨설팅 원칙**: 자금을 연결하는 것이 아니라 **기업의 자금조달 역량을 지속적으로 키우는 것**. 크레탑 조회로 현재 위치 파악 → 3층 구조(신용→특허→인증) 순서로 역량 축적 → 결산·정관·임원퇴직금·연구소·인증을 일상 경영 구조로 정비
- **사례를 읽는 법**: 결과가 아니라 **판단 순서**(어떤 리스크를 먼저 발견, 어떤 순서로 해결, 자금을 어떻게 배열)를 본다. 출발점(업종·업력·신용등급·문제 증상)이 비슷한 사례를 설계도로 쓴다
- **컨설팅 3단계 프레임**: 현황파악(크레탑·부동산등기부·법인등기부·재무제표 2~3년) → 솔루션 설계(은행 협의 / 정책자금 협의 / 기타 지원정책 조회) → **기업관리(재무·비재무·대표신용·기술력 4영역 지속 관리)**
- **정관은 세무조사 시 첫 번째 제출 서류**: 임원퇴직금 규정이 없으면 초과분은 급여 처리(손금불산입), 중간배당 규정 없이 차등배당하면 가지급금 처리 → 정관 정비는 비용이 적고 효과가 크며 모든 절세·자금 전략의 전제 조건

## 74장. 실전 컨설팅 사례
고객사 진단 → 자금 구조 설계 → 실행 → 사후관리 (4단계 프로세스). 사후관리는 재무등급·비재무등급·대표신용등급·기술력 관리로 이어지고, "등급 관리 → 자금 확보 → 성장 → 다음 자금 → 반복"의 선순환을 만든다.

### 사례 A — 캐리어 유통기업의 4단계 등급 업그레이드
출발점: 신보 운전자금 의존 + **도매업 코드 등록 → 보증 한도 제한적**.

| 단계 | 내용 | 실행 방법 | 결과 |
|---|---|---|---|
| 1 | 재무등급 상승 — 자본금 증가 | 특허 자본화 또는 증자 → 자기자본↑, 부채비율↓ | 신용등급 1단계 상승, 보증 한도 확대 가능 |
| 2 | 업종코드 전환 — 도매업 → 제조업 | 주요 매출이 제조 과정을 거친다면 제조업 코드 추가 등록 후 주업종 전환 | 우대 업종 진입, 한도·금리 개선 |
| 3 | 운전자금 전환 — 신보 → 기보 | 제조업 전환 + 특허 보유로 기보 TCB 평가 신청, 기술보증 운전자금 전환 | 기보 우대 조건, 보증료율 인하·한도 확대 |
| 4 | 시설자금 확보 — 지자체+중진공 병행 | 경기도 중소기업육성자금(시설)과 중진공 기계자금 동시 신청 | 공장 설립 시설자금 확보, 제조업 기반 본격화 |

- **핵심**: 자금을 받는 것이 아니라 **등급과 업종 구조를 바꿔 더 좋은 조건의 자금이 가능한 상태**를 만든 것
- 진단 시사점: 업종코드·주업종 설정이 보증기관·한도를 가르므로 "실제 매출 구조와 등록 업종 일치 여부"가 핵심 점검 항목 (14부 65장, 15부와 연결)

### 사례 B — 폐차장 대표의 정책자금 실무 순서
폐차장은 건설업(F 코드)처럼 **정책자금 접근이 제한적인 업종**. 제한 업종도 단계적 접근으로 가능함을 보여준다.

1. **현황파악** — 필수 자료 4종: 크레탑 조회(신용등급·재무·금융거래 이력, 유료) / 부동산등기부등본(담보 현황·근저당 금액·소유자) / 법인등기부등본(대표자 이력·주주·이사회) / 최근 2~3년 재무제표(성장성·수익성·안정성)
2. **솔루션 설계** — 3방향: 은행 협의(주거래은행 한도·금리 개선 가능성 사전 타진) / 정책자금 협의(기보·신보·중진공·지자체 중 적합 자금 선별) / 기타 지원정책 조회(R&D 과제·바우처·고용지원금·인증 지원)
3. **기업관리** (가장 중요한 단계) — 4개 영역 동시 관리

| 관리 영역 | 관리 내용 | 실행 주기 |
|---|---|---|
| 재무등급 | 가결산 모니터링, 5개 불량 항목(가지급금 등) 정리, 핵심 지표 관리 | 분기별 가결산 점검, 연간 결산 전 최종 조정 |
| 비재무등급 | 사업현황서 내용 업데이트, 거래처 다양화, 추정재무제표 현실화 | 연 2회 이상 |
| 대표신용등급 | 개인 신용 연체 없음, 개인 차입 관리, 카드 결제 정시 이행 | 월별 자가 점검 |
| 기술력 | 특허 출원·등록, 인증 갱신, 연구소 사후관리, TCB 등급 향상 계획 | 인증 유효기간 캘린더 관리 |

## 75장. 경영분석 제안서 — 컨설턴트의 실전 도구
- 첫 미팅 최다 질문 "우리 회사는 지금 자금을 받을 수 있나요?" → **15분 안에 답**할 수 있어야 하고, 그 도구가 크레탑 조회
- **제안서의 역할**: 재무·비재무·기술 현황을 한 장에 정리하고, 현재 등급의 원인과 개선 방향 제시 ("이 부분이 등급을 낮추고 있다 → 이렇게 바꾸면 조건이 이렇게 달라진다")
- 컨설턴트의 가치는 **자금 신청 대행이 아니라 경영 진단**에서 나옴. 처음 10분 안에 F·T 프레임으로 현황 정리 → 빨강·노랑·파랑 신호 분류 → 자금 로드맵 제시

### 경영분석 제안서 2대 방식
| 방식 | 특징 | 적합 상황 |
|---|---|---|
| A | 정량 지표 중심, 재무비율 체계적 분석, 표준화된 양식 | 재무 분석 중심으로 객관적 수치 제시가 필요할 때 |
| B | 정성 평가 포함, 사업 구조·시장·비전 포함, 금융기관 제출용 | 종합적 기업가치 평가와 금융기관 설득 자료가 필요할 때 |

- 차이는 형식이 아니라 **목적**: 초기 상담용 = 대표가 문제를 인식하게 만들기 / 심화 제안서 = 구체적 실행 경로 설계

### 제안서 1장 요약 (9개 섹션) — 구성 참고
① 기업 개요 ② 경영진단 종합평가(성장성·수익성·안정성·활동성·생산성 5축 레이더 + 종합등급) ③ 주요 재무지표 3년 비교 ④ 재무분석 Key Finding ⑤ 비재무·기술 경쟁력 분석 ⑥ 자금 수요 및 활용 계획 ⑦ 최적 자금 조달 구조(안) ⑧ 기대 효과 ⑨ 컨설팅 서비스 제공 내용
- 책 그림은 **가상 예시**(매출 320→370→420억, 부채비율 120.5→105.3→93.8%, 종합등급 A-, 자금수요 50억, 조달안 정책자금 20억+보증 30억+금융권 30억). `[확인 필요]` 자금 수요 50억과 조달 합계 80억이 서로 달라 예시 수치로만 참고

### 크레탑 조회 — 첫 번째 도구
| 조회 항목 | 활용 |
|---|---|
| 기업 신용등급(AAA~D) | 현재 등급 확인 → 접근 가능 자금 즉시 판단 |
| 재무비율 분석 | **5개 불량 항목**(가지급금·가수금 등) 여부 |
| 금융 거래 이력 | 현재 차입·연체 이력·보증 현황 |
| 대표자 정보 | 대표 신용, 관련 기업 현황 |
| 매출 추이 | 최근 3~5년 성장률 |
- 크레탑 + 실제 재무제표 교차 분석 → 조달 가능 규모와 최적 경로를 **90% 이상 정확**하게 설계(책 주장). 고객 앞에서 함께 보면 대표 스스로 문제의식을 갖게 되는 효과

### 여신컨설팅 실전
**여신신청서 핵심 기재 4항목**: 여신현황(시설대·운전대·보증서·신용·B2B·외환자금 — 차입 구조 전체) / 담보물 현황(주소 1~3건, 시세·감정가, 담보제공자 관계 — 추가 담보 여력) / 업체현황(제품·종목·업태·설립일·종업원·매출·크레탑·결제방법·대표신용·압류·연체·인증서 — 비재무 전체) / 특기사항(발전성·매출 증대·계약 성사 등 긍정 신호)

**여신 준비서류 6종 (상담 전 확보)**
| No | 서류 | 용도 |
|---|---|---|
| 1 | 사업자등록증 사본 | 업종코드 확인 → 우대/제한 즉시 판단 |
| 2 | 신분증 사본(대표이사) | 대표 개인 신용 조회 동의 |
| 3 | 주주명부 + 법인등기부등본 | 법인 필수, 지배구조·대표 이력 |
| 4 | 부가세과세표준증명원(당해연도) | 매출 실적 검증, 재무제표와 대조 |
| 5 | 비교식 재무제표 3년 | 5개 불량 항목·15개 재무지표 분석 |
| 6 | 금융거래확인서(여신 거래 은행만) | 현재 차입 조건·한도·잔액, 대환·추가대출 전략 |

**은행권 신용대출 4대 방식**
| 방식 | 내용 | 포인트 |
|---|---|---|
| TCB 기술평가 신용대출 | TCB 결과로 담보 없이 은행 직접 신용대출 | 특허·연구소·이노비즈 보유 기업 우선 |
| 보증서 대환 + 신용 | 기존 보증서 대환 시 신용대출 추가 병행(층 조달) | 갱신 타이밍에 신용 추가 협상 |
| 담보 후순위 + 신용 | 선순위 담보 설정 후 후순위(견질담보) 추가 신용대출 | 자가주택 활용 후순위 설정 가능, 법인 대출에 담보 제공 가능 |
| 은행 협약보증 + 신용 | 재단+은행 협약보증(예: 경기재단+신한 2억, 경기재단+하나 8억)에 추가 신용 병행 | 은행별 협약 상품 상이, 사전 확인 |

**금리 구조와 인하·한도상향 루트**
- 금리 = **MOR 기준금리 + 가산금리**(예금보험료·신보출연료·교육세·신용평가위험·근저당설정비·감정평가비 등) **− 이자할인**(지점할인·급여이체·카드·퇴직연금 등). 보증비율이 높을수록 가산금리↓(100% 보증 시 최저). 부수거래로 추가 할인 가능
- **8대 루트**: ① C1·C2 온렌딩 ② TCB 신용 ③ V+협약보증 ④ 시·도자금 연계 ⑤ 본점 승인 ⑥ 기술창조형 기술금융(특허) ⑦ 재활용 육성자금 ⑧ 문화체육관광부 육성자금

**창업중소기업 세금 감면 — 공장 취득 시 반드시 확인**(수도권과밀억제권역 외 창업 중소기업 또는 창업벤처중소기업 대상)
| 항목 | 내용 |
|---|---|
| 취득세 | 창업일부터 4년 이내 취득하는 사업용 재산 **75% 감면**(지방세특례제한법 제58조의3) |
| 재산세 | 창업일부터 5년간 **50% 감면** |
| 등록면허세 | 면제 — ① 창업중소기업의 법인설립 등기 ② 창업 중 벤처기업으로 확인받은 중소기업이 확인일부터 설립하는 법인설립등기 |
| 주의 | 공장 매입 후 추가 비용(취득세·설비·인력충원·부자재) 집중 → **초기 유동성 위기** 가능, 매입 전 운전자금 동시 확보 필수 |

**소재부품인증**: 한국은행 금융중개지원대출(지방소재 기업 우대), 중진공·신보·기보 기술력 인증 확보에 활용. 인력지원(산업기능요원·병역지정업체 가점) / 사업화·경영지원(금융중개지원대출) / 기술지원(소재부품기술개발·신뢰성기술확산·글로벌 동반성장 R&BD 가점). 소재부품 제조기업은 MCT-NET(소재부품 종합정보망)으로 취득 검토
