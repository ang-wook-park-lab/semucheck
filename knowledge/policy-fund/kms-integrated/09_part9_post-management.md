# 9부: 정책자금 사후관리 (37~42장)

정책자금의 가장 큰 리스크는 탈락이 아니라 **승인 이후 관리 실패**. 신청서의 사업·자금·투자·고용·R&D 계획은 승인 후 **기관과의 약속**이 된다.

사후관리 3관점: ①자금 용도 관리 ②기업 상태 유지(인증·연구소·특허·고용·사업장·대표자·지배구조) ③다음 자금으로 이어지는 신용 관리

## 37장. 핵심 원칙

### 항상 답할 수 있어야 할 4가지 질문
1. 승인받은 목적에 맞게 사용했는가?
2. 사용 시기·금액이 약정과 일치하는가?
3. 세금계산서·계약서·이체확인증 등 증빙이 완비됐는가?
4. 수령 당시 기업·인증 요건이 지금도 유지되는가?

### 3대 의무: 용도·기간·증빙
- 용도: 시설자금 = 기계·설비·공장·장비 / 운전자금 = 원재료·인건비·외주비·임차료·마케팅 / R&D = 연구개발
- 기간: 특히 시설자금은 승인 후 정해진 기간 내 계약·발주·설치·대금지급. 미집행 시 약정 해지·축소·재심사·조기상환
- 증빙: 세금계산서, 계약서, 거래명세서, 견적서, 발주서, 검수확인서, 이체확인증, 통장내역, 사진, 납품확인서, 인건비 지급명세서

### 사후관리 실패 4가지 결과
1. **조기회수** (목적 외 사용·약정 위반)
2. **가산이자·환수** (이자혜택·보조금·출연금·세제혜택 반환, R&D 참여제한)
3. **신규 신청 제한** (기관 간 정보 공유)
4. **기한이익 상실** (잔여 대출금 전액 즉시 상환 요구)

### 역할 분담
- 대표: 목적 이해, 회사·개인 자금 분리, 주요 집행 최종 결정, 가지급금·개인 신용 관리
- 재무담당: 통장·장부·세금계산서·계약서·이체확인증 연결, 파일링 체계
- 연구소 담당: 연구노트, 과제일지, 연구원 근무현황, 인건비, 장비 사용기록, 변경신고
- 컨설턴트: 사전 점검·경고(목적 외 사용, 인증 만료, 연구소 요건, R&D 정산, 세액공제 중복)

## 38장. 집행 증빙과 회계처리

### 정책자금 전용 통장 원칙
1. 입금 계좌 별도 지정
2. 집행 비용을 신청서 사용 목적과 연결
3. **대표자 개인 계좌로 직접 이체 금지**
4. 현금 인출 최소화
5. 지출 건별 세금계산서 + 이체확인증 함께 보관
6. 월말 통장 잔액 vs 집행계획 잔액 대조

### 지출 1건당 증빙 세트
견적서 / 계약서·발주서 / 세금계산서 / 거래명세서 / 이체확인증 / 통장내역 / 검수·납품확인서 / 설치사진·결과물 / 내부 품의서·지출결의서
- 시설자금: + 장비 일련번호, 사업장 배치사진
- 운전자금: 특수관계자 거래, 대표자 관련 비용, 가족회사 이체, 현금성 지출은 엄격 관리
- 폴더: 01_시설자금 / 02_운전자금 / 03_R&D과제비 / 04_인건비 / 05_기관제출자료 / 06_사후점검대응
- 파일명: `2026-06-15_A기계_레이저가공기_55,000,000원_세금계산서.pdf`

### 장부와 사용계획서 정합성
- 기관 교차 확인 자료: 신청서, 사용계획서, 약정서, 통장내역, 세금계산서, 회계장부, 부가세 신고, 법인세 신고, 재무제표, 현장 실물
- 시설자금 장비는 비용이 아니라 **유형자산** 처리 검토
- 부가세 신고자료와 집행자료 불일치 주의
- 세무대리인에게만 맡기지 말고 내부 담당자가 사용계획서와 장부를 함께 관리

### 항목별 주의
- 인건비: 4대보험 가입, 근로계약서, 급여대장, 계좌이체. R&D는 참여율·기간·수행기록. **가족·특수관계인·형식상 근로자** 엄격 검토
- 외주비: 계약서, 과업지시서, 결과보고서, 납품물, 검수확인서. 특수관계 회사는 필요성·가격 적정성·실재성
- 장비: 사진, 설치장소, 일련번호, 감가상각. 중고는 시세 적정성·이전 입증

## 39장. 목적 외 사용·환수·기한이익 상실

### 목적 외 사용 유형
1. 시설자금을 원재료·급여·임차료·**기존 채무 상환**에 사용
2. 운전자금을 대표자 개인 계좌·카드대금·생활비·개인 대출 상환에 사용
3. 신청서에 없는 항목(차량, 접대비, 관계회사 대여금)
4. R&D 자금을 연구 무관 비용(일반 영업비, 대표 보수, 연구 외 장비)에 사용
- 판단은 계정과목이 아니라 자금 흐름·상대방·계약·결과물·사업 관련성 종합

### 허위 증빙·부정수급 (가장 위험)
실제 납품 없는 세금계산서 / 장비 가격 부풀려 차액 환급 / 결과물 없는 용역비 / 특수관계사 허위 계약 / 미근무자 인건비 / 연구 무관 비용의 과제비 처리
→ 환수, 제재부가금, 참여제한, **형사 문제**. "거래처·관행·컨설턴트가 괜찮다고 함"은 변명이 안 됨, **최종 책임은 수령 기업**

### 환수·제재·참여제한
- 환수: 부적정 사용 금액 반환(시설자금 전용 시 조기상환·회수)
- 제재부가금: 부정수급·허위 집행 시 추가 부과
- 참여제한: 일정 기간 정부지원사업·정책자금 신청 제한(R&D·바우처·인증 연계에도 불리)

### 사전 통제 내부 절차 8단계
1. 집행 전 사용 목적 검토 / 2. 증빙 가능 여부 확인 / 3. 특수관계자 거래 사전 검토 / 4. 현금 지출 최소화 / 5. 세금계산서·이체확인증 동시 확보 / 6. 월별 집행내역 내부 점검 / 7. 분기별 외부 전문가 검토 / 8. 사후점검 대비 파일링
- "먼저 쓰고 나중에 맞추는 돈"이 아니라 "쓸 수 있는 항목인지 먼저 확인하고 집행하는 돈"

### 기한이익 상실 사유
원리금 연체 반복 / 목적 외 사용 / 허위 서류 / 완전자본잠식 등 중대 재무 악화 / 대표자 파산·회생·신용불량 / 폐업·장기 휴업 / **사업장 이전·대표자 변경 미신고** / 담보·보증 약정 위반
→ 신용정보 등록, 보증 사고, 타 금융기관 회수, 신규 보증 제한, 대표자 신용 악화로 연쇄
- **연체 전에 먼저 연락**(만기 연장·원금 유예·분할 조정 가능성)
- 대표 매월 3가지: ①향후 3개월 원리금 납부 가능 ②사용 목적과 실제 집행 일치 ③자본잠식·체납·대표자 신용 문제 가능성

## 40장. 인증·연구소·R&D 사후관리

- 인증 취소 시 영향: 금리 우대, 보증한도 우대, 세액공제, 지방세 감면, R&D 가점, 조달 우대 → 추징 가능
- 자주 놓치는 것: 유효기간 미확인, 만료 직전 갱신 착수, 취득 당시 요건 유지 미점검, 인력·매출·R&D 투자비율·주소 변경 미반영, 담당자 퇴사로 이력 단절, 갱신 일정표 없음
- **인증 관리는 만료 최소 6개월 전부터**
- 연구소 4대 관리: 연구전담요원 유지 / 연구공간 유지 / 연구활동 증빙 / 변경신고·연간 보고

### R&D 정산 문제 항목
과제 무관 인건비 / 참여연구원 허위 등록 / 참여율과 실제 업무 불일치 / 장비 사적 사용 / 외주 결과물 미비 / 특수관계자 거래 적정성 / 회의비·출장비·재료비 증빙 부족 / 출연금과 세액공제 중복 / **협약 변경 없이 계획과 다르게 집행** / 결과보고서와 회계자료 불일치

### 세액공제와 정부지원금 중복 리스크
- 흔한 실수: R&D 과제비 인건비 전액 공제, 지원금 구입 장비 공제 반영, 과제비·자체 R&D비 미구분, 연구소 회계와 법인세 신고 불일치, 세무대리인이 지원금 집행내역 모름
- R&D 비용 3구분: ①정부지원금 집행분 ②기업 자체 부담분 ③과제 무관 일반 R&D비
- 세액공제 전 세무대리인에게 협약서·사업비 사용내역·지원금 입금내역·부담금 집행내역 제공

## 42장. 사후관리 실패 사례

| 사례 | 내용 | 예방 |
|---|---|---|
| 목적 외 사용(화성 A사) | 시설자금 일부를 미지급금 상환·급여에 사용, 장비 일부만 구입 | 시설·운전 구분 신청, 시설자금 전용 통장, 운영비는 별도 운전자금·만기조정·추가보증 |
| 연구소 취소·추징(군포 B사) | 핵심 연구원 퇴사 후 미채용·미신고, 공간을 사무실로, 연구자료 없음 → 세액공제 일부 추징 | 요원 변동 즉시 보고, 변경신고 확인, 연구노트 월별, 공간 사진·장비 현황, 공제 전 요건 재점검 |

| 기한이익 상실 위험(용인 D사) | 대표자 개인 대출 연체·개인회생 검토 → 법인 대출 추가 점검 | 개인·법인 대출 함께 관리, 개인 연체 차단, 법인 자금 사적 사용 금지, 가지급금 최소화, 개인 세금 체납 방치 금지 |

- 정책자금은 받는 순간부터 **다음 심사가 시작**된다
