- R&D 출연금 = 상환 의무 없는 정부지원금(정책자금 아님). 기업부담분은 세액공제와 동시 작동
- **2026 중기부 R&D 예산 2조 1,959억(전년 1조 5,170억 대비 45% 증액, 역대 최대)** → 신규 과제 증가·경쟁률 완화, 도전 적기(책 기준)

| 대표 이공계 학력, 관련 대기업 경력 | 대표가 기술 이해 못함 |
| 특허 보유, 연구소·전담부서 운영 | 매출 0·사업 실체 불분명 |
- 매출 과다 기업은 "왜 국가 지원?" 역질문. 소액 거래 증빙 + 기술력 있는 창업기업이 이상적

### 참여 제한
| 항목 | 내용 | 해결 |
|---|---|---|
| 세금 체납 | 기업·대표·과제책임자 중 1명이라도 | 납부 즉시 해제, 분납 가능 |
| 신용불량 | 기업·대표·책임자 연체·부도 | 신용 문제 없는 공동대표·CTO를 책임자로 |
| 부채비율 | 1,000% 초과(일부 500%) 또는 전액 자본잠식(직전 재무제표) | 증자, 가지급금 자본전환 |
| 중복과제 | 동일 기술·목적 다른 정부과제 수행 중 | NTIS 조회, 목표 차별화 |
| 기개발 제품 | 양산·판매 제품 포장 | "다음 버전"·"핵심기능 추가"로 재설계 |
| 지역과제 | 해당 지역 본사·공장·연구소 | 공장등록증·연구소 인정서 |
- 기개발·중복은 시스템이 자동 차단 안 함 → 사후 발각 시 **전액 환수 + 3~5년 참여 제한**
