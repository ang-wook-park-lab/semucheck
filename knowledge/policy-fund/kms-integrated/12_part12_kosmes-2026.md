# 12부: 중진공 정책자금 2026 완전판 (55~59장)

- 6대 자금, 최대 100억, 신용등급 대신 기업평가
- **융자 vs 이차보전**: 이차보전은 **중진공과 연계해 평가받은 시중은행 대출에만** 적용. 은행 대출 먼저 받고 나중에 이차보전 신청 불가
- 2026 신설 **정책자금 내비게이션**: 기본 정보만으로 적합 자금·융자 제한·일정·예산 확인 → 신청 전 가장 먼저 활용(스케일업·팩토링·R&D 연계 자금은 지역본지부 상담)
- **불법 컨설팅 주의**: 중진공 직원 사칭, 승인 보장, 과도한 수수료, 보험·투자 상품 강요 → 적발 시 **3년간 융자 신청 제한**
- 매월 **첫째 주만 온라인 접수**, 1~2월 예산 최속 소진
- 2026부터 납세·4대보험·재무제표 **자동 연계** → 미납 사실 즉시 드러남
- 현장평가가 진짜 당락: 주소·실제 위치 일치, 영업 흔적, **대표 3분 사업 설명**, 항목별 금액 근거, 서류·면담 숫자 일관성
- 병행 전략: **중진공 시설자금 + 기보·신보 운전자금**

## 56장. 신청 절차 5단계
| 단계 | 내용 | 준비 |
|---|---|---|
| 1 기업정보 입력 | 홈페이지 기본정보 | 사업자번호·업종코드·업력 정확히 |
| 2 정책우선도 평가 | 기존 세금·재무 데이터 기반 정책 적합성 | 자동 연계 |
| 3 융자 신청 | 신청서 작성 | 자금 목적·금액 근거 |
| 4 기업평가(현장) | 사업장 방문·대표 면담·서류 실사 | 사업장 정비, 대표 설명, 서류 일관성 |
| 5 융자결정·실행 | 금액·금리·기간 결정, 은행 약정 | 담보 절차 |
- 탈락의 절반은 **절차상 실수**(창구 잘못 선택, 기한 놓침, 현장평가 일정 미조율)
- 예산은 상반기에 50~60% 소진, 1월에 연간 20~30% 소진되기도 → **월초 첫 영업일 신청**
- 2026.1 접수(책): 서울 1/5~1/6, 경기·인천 1/7~1/8 등 지역별 이틀
- 수시 접수: 재도약지원, 재해중소기업, 긴급경영안정(위기 증빙)

### 서류
- 자동 연계: 납세증명서, 4대보험 납부확인서, 재무제표(국세청), 사업자정보
- 직접 제출: 융자 신청서, 사업계획서, 담보 서류, 일부 증빙

### 융자 제외 업종(주요)
금융·보험, 부동산 임대, 사행성 오락, 유흥·단란주점 등 일부 음식점, 담배 소매, 복권 판매, 의원·병원 등 보건업 일부(자금별 상이)

### 융자 제한 상태
휴·폐업 / 국세·지방세 체납 / 4대보험 체납 / 신용불량·연체 / 기존 중진공 대출 연체 / 부당개입 적발로 3년 제한 중
- 현장에서 가장 자주 걸리는 3가지: **세금 체납, 업종별 부채비율 초과, 운전자금 누적 한도(25억) 초과**

## 57장. 정책자금 내비게이션
- 기능: 적합 자금 추천 / 융자 제한 여부 / 신청 일정 / 예산 현황
- 판단 어려운 자금(지역본지부 상담): 스케일업, 팩토링(밸류체인안정화), R&D 연계 특수자금
- 트랙 I(직접탐색: 컨설턴트 동행 시 적합) / 트랙 II(자동추천: 처음인 기업, 단 추천이 최적 보장 아님)

### 이차보전
- **이차보전율 3%**: 중점지원분야(혁신성장·초격차·신산업·뿌리·소부장·지역주력) 또는 최근 1년 수출 10만불 이상 / **2%**: 그 외
- 한도 연간 5억(우대 10억), **3년 만기일시상환, 운전자금 한정**. 보전율 ≥ 대출금리면 대출금리 수준으로 조정
- **이차보전 대출은 중진공 기업당 한도(60억) 산정에서 제외**
- 업력 15년 초과 + 신용 양호 기업은 이차보전 우선 대상(수시 접수)

### 투자조건부 융자
- 신청일 전 24개월 내 투자기관 1억 이상 선투자(또는 예정) + 투자계약서·확약서
- 연간 20억, 5년(거치 2년), 기준금리−0.3%p, 운전자금
- 융자액 5% 이내 신주인수권 취득(전액 상환 시 소멸), 행사가 = 선투자 기업가치
- **후속투자 유치 시 투자금의 20% 조기상환**(최대 대출금 20%)

### 성장공유형 대출 (CB·BW·RCPS·CPS 인수, 기업당 20억)
- CB·BW: 업력 7년 미만 7년(거치 4년) 표면 0.25%·만기보장 3% / 7년 이상 5년(거치 2년) 표면 0.50%·만기보장 3%
- RCPS: 상환권 행사 시점(2년 또는 3년)부터 연 5% 단리
- 사업장 건축·매입 시설자금 불가. 비수도권·창업기업·투자누계 3억 이하 중점

### AI 스프린트 우대트랙 (2026 신설)
정책우선도 평가 생략, 금리 0.1%p 추가 인하, 잔액 한도 100억, 혁신성장지원자금은 시설과 별도 운전자금 가능 → **AI 기업은 선정 여부 먼저 확인**

### 대출금 사전검증 시스템 (2026 명문화, 의무)
- 대상: **운전자금 3억 초과** / 청년전용창업 / 재창업 / 선제적 자율구조개선 대출기업
- 수수료 0.06%(VAT 별도) → 동액 이자 감면
- 미이행 시 용도 외 사용 → **조기회수 + 3년 융자 제한** → 컨설턴트의 사후관리 안내 의무

### 한도 우대
- 기본 잔액 60억, **지방 소재 70억**, 아래 해당 시 **100억**
  - 자금 유형: 협동화·협업 승인 / 제조현장스마트화 / 긴급경영안정 / 사업전환·재편 승인 / AI 스프린트
  - 정책 우대: 소부장 강소100·스타트업100·경쟁력강화위 추천 / 원전 협력 / 혁신형 중소기업 / 초격차·신산업 / 도약 / 아기·예비유니콘 / 초격차 스타트업 / 국가핵심기술 / 여성·장애인·사회적경제 / 일자리 으뜸 / 해외복귀 / 글로벌 강소 1000+
- **운전자금 연간 5억 → 10억 우대**: 최근 1년 10인 이상 고용 / 수출 50만불 & 20% 증가 / 매출 30억 & 3년 연평균 20% / 최근 1년 20억 이상 시설투자 / 초격차·소부장 강소·여성·장애인·TIPS 졸업·도약·유니콘 등

### 5년 내 3회 제한의 예외
- **4회 가능**: 시설자금 / 1년 내 10인 이상 고용 / 수출 50만불 & 20%↑ / 매출 30억 & 3년 연평균 20%↑ / 소부장 강소·스타트업100 등 / **운전자금 누적 5억 이하 소액**
- **5회 가능**: 중점지원분야 시설자금 / 초격차 스타트업 창업기반(시설)
- **횟수 미산정 자금**: 재도약지원, 긴급경영안정, 매출채권팩토링, 동반성장네트워크론, 이차보전, 뷰티론, 통상리스크대응, 신시장진출(수출국 다변화)

### 제3자 부당개입 (사기)
- 사례: 컨설팅 대가로 대표 명의 생명보험(월 200만원 20년) 강요 → 금감원 / 중진공 로고 무단 현수막 → 상표법 수사 / 직원 사칭 수수료 대행
- 합법: 사업계획서 방향 자문, 서류 체크, 자금 종류 안내 / 불법: 직원 사칭, 승인 보장, 과도한 수수료, 보험·투자 연계 강요
- 의심 시 **융자 신청 취소 또는 3년 제한**, 신고: 중진공 누리집 제3자 부당개입 신고센터
- "제가 연결해야만 된다"는 말은 즉시 의심

## 58장. 자금별 심사 포인트
| 자금 | 현장 질문 |
|---|---|
| 혁신창업사업화 | 아이템이 시장에서 통할까? 자금을 시제품·마케팅·운전에 어떻게? |
| 신시장진출 | 수출실적·해외진출 근거? 바이어·수출계획·시장조사? 자금이 수출 확대와 직결? |
| 신성장기반 | 왜 지금 설비투자·스마트화? 투자 후 생산성·매출·원가 개선 수치? 견적서·투자일정 구체? |
| 재도약 | 이전 실패 원인? 재창업·전환 모델이 어떻게 다른가? 계획·일정 현실적? |
| 긴급경영안정 | 매출감소·재해·애로 입증? 자금 지원 후 정상화 계획? |
| 밸류체인안정화 | 매출채권·발주 확정? 자금이 원재료·생산·납품과 어떻게 연결? |
- 공통 5가지: 사업장 실재성 / 서류 숫자 정합성 / 자금 사용계획 구체성 / 대표 답변 일관성 / 세금·4대보험·기초관리
- 혁신창업 심사: 기술·사업성(시장규모·차별성) / 대표 역량(이력·수상·지원사업 경험) / 자금계획(항목별 금액·근거·타임라인) / 성과목표(6개월·1년 매출·고용·수출) / 결격
- 신성장기반 우대: 스마트공장, 디지털 전환(ERP·MES·빅데이터), 탄소중립, 소부장 국산화. "설비 노후" ✗ → "월 200개 한계, 신규 수주 350개 → 생산량 75%↑" ○
- 재도약: "열심히 하겠다" ✗ → "실패 원인 X, 이번엔 Y로 해결" ○
- 밸류체인안정화(팩토링): 대기업·공공 납품, **결제주기 60일 이상** 기업, 세금계산서·발주서·납품계약서

## 59장. 현장평가 준비
- 진짜 당락 = 4단계 현장평가. 핵심은 대표의 사업 설명, 재무 즉답, 자금계획 구체성

### 당일 체크리스트
- 사업장: 등록지 주소 = 실제 / 영업 흔적(기계·재고·직원) / 간판·현판 / 주요 거래처 계약서·발주서 비치
- 대표 면담: **3분 사업 설명** / 자금 목적·금액 근거 즉답 / 거래처·매출 구조 / 6개월·1년 성과 목표 수치 / 재무 주요 숫자(매출·이익·부채)
- 서류: 사업계획서 숫자 = 재무제표 / 자금 사용내역 = 신청서·계획서 / 계약서 금액 ↔ 재무자료

### 질문별 답변 방향
| 질문 | 방향 |
|---|---|
| 자금을 어디에? | 항목별 금액·타임라인("설비 X 구매 Y억, 원자재 Z천만") |
| 성과 목표? | 수치 + 근거("A사 수주 확정") |
| 주요 고객사? | 상위 3개사 이름·연간 거래규모·관계 기간 |
| 경영이 어려운 이유? | 솔직히 인정 + 해결 계획 |
| 다른 금융기관 대출? | **숨기지 말고 전부 공개**(은행 조회로 확인됨) |

### 병행 전략
| 조합 | 주의 |
|---|---|
| 중진공 시설 + 기보·신보 운전 | 총 차입 규모·부채비율 영향 사전 확인 |
| 중진공 창업자금 + 사업화 패키지(무상) | 무상 수혜 이력이 가점 |
| 중진공 + 지자체 자금 | 동일 용도 중복 제한 가능 |
- 3원칙: **타이밍**(매월 첫째 주, 1월) / **일관성**(신청서·계획서·재무제표·대표 설명) / **구체성**(얼마·어디·왜·결과)
