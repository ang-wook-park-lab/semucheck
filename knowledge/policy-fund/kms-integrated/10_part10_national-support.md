## 44장. 심사위원장이 밝힌 가점·감점

### 가점 5대 요소
1. **인력 구성**: 팀원 배경과 아이템 연결(교수·박사·대기업 실무), 외부 자문단·멘토로 보강. 학생창업팀 불리
2. **매출 규모**: 적당히 있음 > 매우 많음 > 별로 없음 > 전혀 없음. 소액이라도 실거래 증빙
3. **국가 인증**: 기업인증(직무발명우수·성과공유·벤처·이노비즈·메인비즈·연구소, 정량 최대 3점) / 기술인증(NET·NEP 등) / 품질인증(ISO 9001·14001 등) / 산업표준(KS 등)
4. **대의명분**: 사회적 가치와 연결된 문제 정의(문제인식에 사회적 필요성, 수익모델은 성장전략에)
5. **특허 포트폴리오**: 3개 이상 > 1~2개 > 0개, **TCB 특허 0~7개 누진, 7개 등록이 만점**

### 청년창업사관학교 등 가점 (책)
- 서류: 관련 특허·실용신안(출원 포함) 0.5 / 여성 대표 0.5 / 프리스쿨 심화 수료 / 전년 우수 등급 0.5 / 전국 창업경진대회 수상(2년) 0.5 / 사회적경제기업 1.0 / 소셜벤처 청년인턴 0.5 / **근로자 미래성과공유제 1.0 / 내일채움공제 가입 1.0 / VC·AC 투자 실적(3천만+) 1.0** / 영상인터뷰 0.3
- 발표: **팀창업(2인 이상) 2점** / 내일채움공제 1명당 1점 / 일자리안정자금 1점 / 스톡옵션 1점 / 관련 특허 최대 5점(출원 0.5) / 경진대회 수상 0.5(최대 1) / 성과공유기업 1점 / 감염병 관련 1점 / 고용·산업위기지역 1점

### 감점 4대 요인
1. 기존 시장 완전 부정("완전히 새로운 시장") → "기존 시장 + 차별화"로
2. 근거 없는 경쟁사 비방 → 객관적 수치 비교
3. **지나친 진정성 호소**("진정성 있는 어필은 탈락의 지름길")
4. 건방진 태도("경쟁자 없다", "실패할 이유 없다")

## 45장. 예비창업패키지 사업계획서

| 장 | 핵심 질문 | 실수 |
|---|---|---|
| 1 문제인식(Problem) | 문제가 실재하는가 | 문제를 너무 크게·모호하게 |
| 2 실현가능성(Solution) | 해결할 수 있는가 | 아이디어만 있고 준비 없음 |
| 3 성장전략(Scale-up) | 돈이 될 것인가 | 비현실적 매출 계획 |
| 4 팀 구성(Team) | 이 팀이 할 수 있는가 | 대표 역량과 아이템 불일치 |

- 1-1 배경: 외부 배경(통계·보고서) + 내부 동기(대표 경험) + 긴급성
- 1-2 시장: TAM→SAM→SOM 3단계로 구체화
- 2-1 준비정도: 시장조사·고객 인터뷰·시제품·가입 의향 등 **준비의 흔적**
- 2-2 경쟁사 비교: "O/X" 대신 수치("우리 2초 / 경쟁사 15초")
- 3-1 BM: 수익이 언제·어디서·어떻게 나는지 한 문장
- 3-3 집행계획: 비목별 산출 근거(재료비=품목·수량·단가, 외주=내용·기관·금액, 수수료=전시회명·참가비·부스비 분리, 인건비=직위·업무·단가·기간)
- 4-1 대표 역량과 아이템 연결, 4-2 외부 협력기관은 역할·시기·결과물
- 제출 전: **개인정보 마스킹**(미마스킹 시 감점), 안내문구 삭제, 15페이지 이내, 모든 수치 출처, BM 한 문장, 비목별 근거

## 46장. TCB 평가

- TCB = 기보 거래 출발점. 등급이 보증 한도·보증료율·심사 우선순위 결정
- 평가 영역: 기술사업역량(경영주 역량·경영진 역량·기술개발역량·제품화역량·마케팅역량) + 기술경쟁력(기술성·시장현황·제품우위성)
- 세부: 대표 동업종 경험·기술지식, 기술개발조직·인력, **수상실적·지식재산권·R&D 투자비율**, 생산역량·투자 적정성·자금조달능력, 판매처 다양성, 모방 난이도·기술수명·완성도, 시장규모·성장성·경쟁·진입 용이성, 인지도·점유율

| TCB 등급 | 의미 | 보증 활용 |
|---|---|---|
| T1~T3 | 최고~매우 우수 | 최고 한도·최저 보증료 |
| **T4** | 우수 | **일반 한도 상단 (실질 분기점)** |
| T5~T6 | 보통 | 일반 한도 중단, 축소·조건부 |
| T7~T8 | 보통 이하·미흡 | 한도 크게 축소 |
| T9~T10 | 불량 | 보증 거절 가능성 높음 |
- **조달우수제품 등록: 신용등급 BBB 이상 또는 TCB T4 이상**
- 평가기관은 금감원 감독 → 등급 단기 변경 어려움

| 항목 | 방법 | 기간 |

## 47장. IP 금융

- IP 금융 3방식: 담보(IP 담보 대출) / 보증(IP 보증, 신용 한도 외 추가) / 투자(IP 기반 투자)
- 기보 **특신전 조합(특허 + 대표 신용 6등급 이내 + 연구소·전담부서)**: 창업기업은 매출 증빙 없어도 **최대 3억**(2020.1 개정)
- 서울신용보증재단 IP 보증(서울 소재, 등록 후 3~4개월): 개발자금 1억 / 사업화자금 2억 / IP 우대 1억, 보증료 연 1%. 기보+신보+신재 합산 8억 이내면 중복 가능
- 기보·신보·중진공 IP 대출: 대표 신용 6등급 이내 + 특허 등록 후 3개월(또는 SW 저작권), 1~3억(등급별)
- 시중은행 고액 IP 담보대출: BBB- 이상(BB-까지), **최소 3억 이상(특허 가치 합산 3억 미만 불가), 매출 10억 이상**

### 특허 출원 속도
| 방식 | 기간 | 특징 |
|---|---|---|
| 가출원 | 즉시 | 1년 내 정식 출원 |
| 일반출원 | 1.5~2년 | 비용 최소 |
| 우선심사 | 7~9개월 | 사업화 중·모방 우려 |
| 초우선심사(예비심사) | 2~5개월(평균 100일) | 등록 보장, 실패 시 환불 |
- **분할출원**으로 하나의 원출원에서 복수 특허 → TCB 특허 7개 만점 확보 전략

### 특허 자본화(현물출자)
- 효과: 가지급금 정리, 미처분이익잉여금 정리, 부채비율 개선, 신용등급 상향, 법인세 절세, 법인자금 개인화, 가업승계 절세
- 절차: 대표 명의 특허 등록 → 가치평가(발명진흥회·중앙기술평가원·감정평가법인) → 감정보고서 → 주주총회 결의 → 법원 승인 → 자본금 증가 등기 (통상 5~6개월)
- 효과 예(책): 5억 기준 약 1.4억, 10억 기준 약 2.8억 절세(급여 지급 대비)
- 주의: 업무 관련성 입증, 시가증자 아니면 기존 주주 증여 문제, 법원의 목적사항 적합성 판단 → **세무사·법무사 사전 검토 필수**
