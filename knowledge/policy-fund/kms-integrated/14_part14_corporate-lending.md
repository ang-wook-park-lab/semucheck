# 14부: 기업여신 기초 — 대출 구조·업종·성장단계 매칭 (63~68장)

## 개요
- 컨설턴트 역할 = **정보 비대칭 해소**(기업·컨설턴트·금융기관 삼각 구조)
- **기업대출 5계단**(아래로 갈수록 저금리, 낮은 계단 최대 활용):
  1. 부동산 담보(연 2~3%) — 감정가의 최대 80%
  2. 보증서(실질 4~5.5%)
  3. 신용·팩토링(4~7%)
  4. 회사채·유동화
  5. 2금융권
- 실무 원칙: **같은 은행 다른 지점에서 동시 기업대출 불가**, 기업대출 이자는 법인세 손금
- 업종코드 21개 우대·제한·금지: 제조업(C)·보건복지(Q) 최우대 / 건설(F)·숙박음식(I) 보증 한도 축소 / **부동산업(L)은 '이름만 우대'(실질 한도 거의 없음)** / 건설+제조 겸업이면 제조를 주업종으로 / IT·전문서비스·교육(J~P)은 기보 TCB 무담보 보증이 강력
- **재무제표 5대 위험 항목**(존재만으로 등급 하락): 가지급금 / 자본잠식 / 개발비 과대계상 / 가수금 / 영업이익 적자(이자보상 1배 미만) → 가지급금·자본잠식은 즉시 정리

### ★ 수임 여부 판단 (5분)
| 판정 | 조건 | 대응 |
|---|---|---|
| **즉시 수임** | 세금 완납 + 대표 신용 5등급 이내 + 매출 증가 추세 + 자금 목적 명확 + 인증 1개 이상 (5개 모두) | 당일 계약 |
| **준비 후 수임** | 세금 완납이지만 가지급금 있음 / 신용 5~6등급 / 인증 없음 | "지금 신청하면 탈락, 3개월 후 이렇게 준비" 로드맵 제시, 준비 컨설팅 |
| **수임 불가** | 세금 체납, 신용불량, 자본잠식, 진행 중 소송, 대표 파산·회생 중 | "이것부터 해결" 명확히 안내 |
- 컴플라이언스: 승인 보장·사칭·과도한 선수금 = 불법 → 고객사까지 3년 제한. 합리적 성공보수 + 투명한 계약서

## 64장. 기업대출 vs 가계대출

| 항목 | 기업대출 | 가계대출 |
|---|---|---|
| 지점 복수거래 | **불가**(한 지점에 기업대출 잔액 있으면 같은 은행 타지점 신규 불가) | 가능 |
| 이자 처리 | 법인 손금(법인세 절감) | 손금 불가 |
| 담보 | 개인 부동산을 법인대출 담보 가능(가계대출 먼저 상환·말소 또는 후순위) | 법인 자산을 가계대출 담보로는 제한 |
| 후순위 | 가능 | 일부 상품 제한 |
| 심사 | 기업 재무 + 사업성 + 대표 신용 | 개인 신용·소득·담보 |

### 기업대출 5계단 (책)
| 계단 | 담보 | 금리 | 기관 |
|---|---|---|---|
| 1 | 부동산(사업장·자가·기타) | 연 2~3% | 시중은행 |
| 2 | 보증서(기보·신보·지역신보·농신보) | 3~4% + 보증료 1.5% = 실질 4~5.5% | |
| 3 | 신용(신용대출·B2B·팩토링·할인어음, TCB 기반) | 4~7% | 시중은행 |
| 4 | 회사채·유동화 | 5% 이상 | 유동화 기관 |
| 5 | 2금융권(저축은행·캐피탈) | 최고 | 최후 수단 |
- 전략: 1계단 감정가 최대 80% → 2계단 보증으로 추가 → 3계단 TCB로 개선 → 4계단 이상은 피하거나 단기 후 대환

### 시설자금 한도 공식
- 담보+신용: 감정가 × 60~65% + 신용 10~15% (예: 감정가 10억 → 6.5억 + 1.5억 = 최대 8억)
- **자기자본 20~30%** 필요(10억 시설이면 2~3억)
- 기간: 3년 거치 + 5년 상환 → 4년차부터 원금 부담 급증, 현금흐름 시뮬레이션 필수
- 대상: 공장·사무소 신축, 기계 구입, 공장·창고 구입, 사업 목적 토지(투기 불가)
- 체크: 감정가는 시세보다 낮게 나옴 / 자기자본 준비 / 기존 담보대출 잔액 차감 / 거치 후 상환 시뮬레이션

## 66장. 지원 형태: 직접·간접·이차보전

| 구분 | 직접대출 | 간접대출 | 이차보전 |
|---|---|---|---|
| 구조 | 정책기관 → 기업 | 정책기관 → 은행 → 기업 | 은행 → 기업, 정부·지자체가 이자 일부 부담 |
| 실행 | 중진공·소진공 | 시중은행 | 시중은행 |
| 핵심 | 정책 적합성 | 은행 심사·재무 안정 | 금리 절감 |
| 예 | 중진공 창업운전, 신성장기반 | 한은 C1·C2, 산은 온렌딩 | 중진공 이차보전, 지자체 이차보전 |
- **이차보전 순서: 중진공 신청 → 평가 → 은행 연계 대출 + 이차보전** (은행 대출 먼저는 불가)

### 용도별 세부 자금
- 운전: **B2B 자금**(구매기업 대금을 은행이 선지급), 무역자금, 외상매출채권 회전대출, 어음할인, TCB 기술금융, 동산담보대출
- 시설: 부동산 담보대출, 기계설비 대출
- B2B 종류: 기업구매자금대출 / 외상매출채권 담보대출 / 구매론(B2B론) → **대기업·공공 납품 기업은 적극 활용**(대기업 신용 기반, 저금리, 간단 심사)

## 67장. 성장단계별 자금 매칭 (제품 개발 주기)

| 단계 | 상태 | 자금 |
|---|---|---|
| 1 기업의 태생 | 아이디어·창업 준비 | 소액창업여신, 예창패, 소진공 |
| 2 1차 제품 제작 | 프로토타입·시제품 | R&D 초기, 중진공 창업운전, 기보 초기보증, 사업화 패키지 |
| 3 1차 양산 + 2차 개발 | 첫 판매 + 다음 제품 개발 | 기보·신보 보증 + 중기부 R&D(디딤돌·전략형) |
| 4 1·2차 양산 + 3차 R&D | 복수 제품 판매·생산 | 중진공 신성장기반 + 기보 확장보증 + R&D 시장대응형 |

### 선순환 설계
창업자금(무상) → 1차 제품 → 기보 초기보증 → 양산·매출 → TCB 상승 → 보증 확대·금리 인하 → R&D 과제(무상) → 2차 제품·특허 → IP 금융 → 2차 양산 → 이노비즈 → 온렌딩·세무조사 유예 → 시설투자 → 3차 R&D → 반복

### ★ 컨설팅 실행 순서
1. 기업 현황: 업력·업종코드·매출·인원·담보자산·현재 대출
2. 단계 진단(1~4단계)
3. 결격 점검: 세금·4대보험 체납, 대표 신용
4. 한도 시뮬레이션: 담보 최대 + 보증 추가
5. 자금 매칭: 단계·현황에 맞는 조합
6. 신청 로드맵: 타이밍·순서·서류 일정
