# 14부: 기업여신 기초 — 대출 구조·업종·성장단계 매칭 (63~68장)

## 개요
- 컨설턴트 역할 = **정보 비대칭 해소**(기업·컨설턴트·금융기관 삼각 구조)
- **기업대출 5계단**(아래로 갈수록 저금리, 낮은 계단 최대 활용):
  1. 부동산 담보(연 2~3%) — 감정가의 최대 80%
  2. 보증서(실질 4~5.5%)
  3. 신용·팩토링(4~7%)
  4. 회사채·유동화
  5. 2금융권
- 실무 원칙: **같은 은행 다른 지점에서 동시 기업대출 불가**, 기업대출 이자는 법인세 손금
- 업종코드 21개 우대·제한·금지: 제조업(C)·보건복지(Q) 최우대 / 건설(F)·숙박음식(I) 보증 한도 축소 / **부동산업(L)은 '이름만 우대'(실질 한도 거의 없음)** / 건설+제조 겸업이면 제조를 주업종으로 / IT·전문서비스·교육(J~P)은 기보 TCB 무담보 보증이 강력
- **재무제표 5대 위험 항목**(존재만으로 등급 하락): 가지급금 / 자본잠식 / 개발비 과대계상 / 가수금 / 영업이익 적자(이자보상 1배 미만) → 가지급금·자본잠식은 즉시 정리

## 63장. 중소기업 현실과 컨설턴트 역할

| 자금 취약 원인 | 결과 |
|---|---|
| 정보 부족 | 지원은 있는데 못 받음 |
| 금융기관 기피 | 좋은 조건 있어도 신청 포기 |
| CFO 부재 | 가결산·신용·타이밍 관리 엉성 |
| 급변 환경 | 알았을 땐 이미 마감 |

### 컨설팅 4대 포인트
현금흐름 관리·조달(월 시뮬레이션, 타이밍) / 비용 절감(저금리 전환, 세액공제, 보증료) / 가치 형성(법인 자산 축적, 사옥, 특허 자본화) / 리스크 관리(차입 분산, 상환 계획, 연대보증 축소)

### 3대 현안
| 현안 | 해결 |
|---|---|
| 한도 부족 | 보증(기보·신보)으로 신용 한도, 담보 감정가 80% 활용 |
| 타이밍 미스 | 연간 자금 캘린더, 가결산으로 적기 파악, 수시 접수 자금 |
| 금리 과다 | 신용·기술등급 향상, 정책자금 전환 |
