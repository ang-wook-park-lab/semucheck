# 기업신용등급 진단 기준 정리

`checklists/credit/credit-diagnosis.json`(55문항)과 `web/src/lib/credit.ts`(재무비율 계산·준비도 점수)의 근거 메모입니다.
**등급 준비도는 참고용 추정이며 실제 신용평가사(NICE평가정보·한국기업데이터·이크레더블)의 모형·등급과 다릅니다.** 업종별 평균이 필요한 지표는 `[확인 필요]`로 표시했습니다.

## 1. 구조 (정책자금 도서 15부 69장)
- 기업등급 = **재무 70% + 비재무 25% + 기술 5%**
  - 재무: 효과가 가장 크지만 시간이 필요(0~6개월, 가결산 조정·불량 항목 정리)
  - 비재무: **사업현황서 작성 방식**으로 비교적 빠르게 개선(대표 신용·자산·이력, 주주현황, 매출처·매입처, 노조, 사업장, 추정재무·비전)
  - 기술: 벤처(약 60일)·연구전담부서(약 15일)로 확실히 채움, BBB와 BB 경계를 넘게 해 주기도 함
- 등급 의미: AAA~A 최우량~우량 / BBB 양호(대부분 정책자금) / **BB 보통(정책자금 기본 접근선)** / B~CCC 주의~취약 / D 부도 / NR 평가 불가. **BB- 진입**이 1차 목표.
- 비재무 감점이 있으면 재무를 올려도 등급이 정체되므로 비재무를 먼저 점검.

## 2. 재무비율 기준 (70장) — `credit.ts`가 입력 숫자로 계산
| 영역 | 지표 | 기준 |
|---|---|---|
| 성장성 | 매출액증가율 | 10% 이상 양호, 마이너스 주의, **−30% 이하 즉시 위험**, 부가세 신고액과 일치 |
| 수익성 | 매출액영업이익률 | 업종 평균 이상, 적자 위험, **전년 대비 2%p 이상 하락 주의** |
| 수익성 | **이자보상배율** | 3배 이상 안정, **1배 미만 즉시 위험** |
| 수익성 | ROA | 3% 이상 양호 |
| 안정성 | **부채비율** | **200% 이하**(업종별 기준 상이), 400% 초과 위험 |
| 안정성 | 자기자본비율 | 40% 이상 양호, 20% 미만 위험 |
| 안정성 | 유동비율 | 150% 이상 안정, 100% 미만 주의 |
| 안정성 | 차입금의존도 | 30% 이하 안정, 50% 초과 위험 |
| 활동성 | 매출채권 회수기간 | 60일 이하 양호, 90일 초과 위험(업종별 상이) |
| 활동성 | 재고자산 보유기간 | 업종별 상이, 120일 초과 시 과잉 재고 주의 |

> 책의 활동성 지표는 회전율이지만, 입력 단위를 맞추기 쉽게 **회수기간·보유기간(일)**으로 바꿔 계산합니다(60일·90일·120일 기준은 일반적인 참고값이며 업종별 `[확인 필요]`).

### 재무제표 5대 위험 항목 (70장)
| 항목 | 본질 | 해결 |
|---|---|---|
| 가지급금 | 자금 유출·불투명성(신보 CCRS 하향 사유) | 급여·배당·상환으로 **즉시** 정리 |
| 자본잠식 | 기술적 파산 | 증자·이익 유보, **즉시** |
| 가수금 | 잠재 유동부채 | 장기차입금 전환 또는 출자전환(DES), **3개월** |
| 개발비(무형자산) 과대계상 | 허수 자산 | 효익 불확실 시 비용처리·상각, **3개월** |
| 영업이익 적자 | 이자도 못 버는 구조 | 원가 개선·비용 삭감·가결산, 결산 전 |
- 정리 우선순위: **즉시**(가지급금 → 자본잠식) / **3개월**(가수금 장기전환 → 개발비 비용처리) / **결산 전**(영업이익 흑자 → 부채비율 200% 이하). 세무사 사전 협의 필수.
- **즉시 위험 신호**: 이자보상배율 1 미만, 자본잠식, 매출 30% 이상 감소 → 점수 상한을 적용(1개 59점, 2개 이상 44점).

## 3. 같은 숫자라도 기관마다 다르게 봅니다 (15부 개요)
- 부채비율 110%: 신용평가(건설업 업종평균 64% 기준)는 감점, 은행 여신(200% 기준)은 양호, 중진공 융자제한(건설업 약 369~404%)은 무관.
- 결산 목적이 4가지(세금·신용등급·여신·정책자금)이고, 신평사·은행은 **재무제표증명원(원본)**을 봅니다. 절세(이익 축소)와 신용(이익 유지)은 반대 방향이라 가결산으로 조정합니다.
- 산업분류코드(지원기관)와 업종분류코드(국세청)는 다릅니다. 코드가 어긋나면 업종 평균 비교와 융자제한 기준이 바뀝니다.
- 신평사는 동종·동규모 대비 상·하위 0~5% 항목에 경고를 표시합니다. 접대비·복리후생비·소모품비 급변, 감가상각 몰아서·안 하기, 세무사 변경 해를 주의 → **비용을 일자형으로 일관 관리**.

## 4. 신보 CCRS 조정 사유 (72장)
- 상향: 자본금 증자 / 수출 50% 이상 / 최근 1년 내 자가 사업장 / 하도급 우수기업 / 결산 후 수주 급증 / 매출채권보험(업력 3년+)
- 하향: 누락된 지급어음·차입금 감안 시 완전자본잠식 / 주요 거래처·관계사 도산 / **가지급금·가수금 보유** / 영업이익·순이익 결손 / 하도급 불공정 통지

## 5. 점수 계산 (참고용)
- 재무 점수: 재무비율 판정(양호 1 · 주의 0.55 · 위험 0, 지표별 가중치)과 결산·세무 정성 문항을 가중 평균
- 비재무 점수: 대표자·사업·거래·신용 이력 문항 / 기술 점수: 기술·인증 문항 (빨강 해당 0 · 노랑 0.4 · 파랑 0.75, 해당 없음 1)
- 총점 = 재무 70% + 비재무 25% + 기술 5%(응답이 없는 요소는 제외하고 비중을 다시 맞춤) → 80점 이상 우량권, 65~79 보통권(BB 전후), 45~64 개선 필요, 45 미만 취약
- 위 구간과 가중치는 이 프로그램의 단순화이며 평가사의 실제 기준이 아닙니다.

## 6. 신용평가사에 대한 일반 지식 (`[실무자 확인 필요]`)
- 중소기업 대상 기업신용평가는 NICE평가정보·한국기업데이터(크레탑)·이크레더블 등이 재무·비재무 정보로 수행하고, 은행은 자체 모형, 신용보증기금은 CCRS, 기술보증기금은 TCB(기술평가)를 씁니다. 모형의 세부 가중치는 공개되지 않습니다.

## 7. 경영 건강진단서 3단계 (73장)
1. 기본(리스크 해소): 신용등급 BB- 진입, 산업분류코드 확인, 특허 첫 출원 / 사업자등록·업종코드 정비
2. 성장: 가지급금·가수금 정리, 적격비용, 주식분산, 특허 등록·IP 담보, 이노비즈·연구소, 정책자금 우선도 60% 이상
3. 안정: 절세 구조 완성(사내근로복지기금 등), 혁신자금·중개자금 최저금리, R&D 연계, 금융구조 최적화
- 자금조달 3층 구조(순서 필수): 1층 신용 → 2층 특허(특허담보 최대 5억) → 3층 인증(혁신자금 = 매출 40% + 특허 30% + 신용 30%, 최대 매출 100%).
